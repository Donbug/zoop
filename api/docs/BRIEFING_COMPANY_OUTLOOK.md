# 선정 기업별 전망 — D-BRF-01·02

기존 전체 기업 시장 요약·시장 지표·핵심 이슈는 유지한다. 선정된 이슈에 실제로 연결된 **기업별 사업 전망**을 별도 `companyOutlooks` 스냅샷으로 저장하고 첫 화면에 제공한다. 지수 방향이나 단기 주가 예측을 기업 전망으로 대체하지 않는다.

## 입력과 생성

`scripts/briefing_company_outlook.py`가 검증된 presentation replay를 소비한다. PoC 추출·묶음·중요도·이슈 선정은 재실행하지 않는다.

- 기업 ID·사건 ID·확인된 사실은 기존 검증 결과에서 복원한다.
- 같은 기업의 원발행 시각이 회차 마감 이하인 배경·신규 자료를 기존 시각 검증 원장 내에서 추가 검색한다. 현재는 기업별 최대 8개 배경 문서의 정확한 인용 구간을 제공한다. 공식 출처를 우선하며 동일 기업 여부·문서 버전·본문 해시·발행 시각을 다시 확인한다. 검색 순위는 전망의 긍정/부정 판단이 아니다.
- 검색 결과의 제목·요약만으로 근거를 승격하지 않는다. 신규 외부 문서는 원문·시각·버전·권한을 확보하고 기존 수집/시각 원장에 등록한 뒤 사용할 수 있다. 이 스크립트는 임의 웹 결과를 자동 등록하지 않는다.
- 생성과 독립 의미 검증을 분리한다. 회사별 사업 영향·조건부 전망·성립 조건·반대 요인·동일 기업 비교를 모두 요구한다. 수치/잠정/계획/약 등의 의미는 원문으로 검증한다.
- 주가 관측값이 없는 현재 입력에서는 가격 흐름·예측 적중/실패를 주장하지 않는다. 확인된 사업 정보의 변화를 비교하고 관측 부족을 표시한다. 다음 단계의 종목별 시세 수집을 KOSPI/KOSDAQ으로 대신하지 않는다.

출근은 가장 최근의 검증된 동일 기업 판단을 새 정보로 갱신한다. 퇴근은 **같은 날 아침 동일 기업**만 비교한다. 아침에 없던 기업에 전날 판단을 끼워 넣지 않는다. 이전 판단이 없으면 신규 판단과 비교 불가 사유를 제공한다. 마감 이후 자료는 사용하지 않는다.

## 저장·조회

기존 `presentationEnrichment.companyOutlookLayer`를 추가한 새 bundle을 **별도 빈 로컬 replay DB**에 import한다. 기존 발행 DB를 수정하는 기능이나 공개 수정 API는 추가하지 않는다. ERD·migration 변경은 없다.

`BriefingCompanyOutlookRules`는 저장 전에 다음을 검사한다.

1. 선정 기업/이슈 전체와 사실 투영, 동일 기업 원문 소유 관계, 실제 본문·인용·URL·발행 시각 일치.
2. 모델 요청/응답 바이트 해시·고정 프롬프트·모델·사용량, 생성 결과와 독립 검증 대상의 정확한 일치.
3. 새 직전 판단의 결과 버전, 같은 날 아침 제한, 이전 실패 및 재생성 이력과 사용량의 보존.
4. PASS 결과만 공개, 실패한 전망은 숨기되 원래 발행·뉴스·시장 요약은 유지.

본문·입력·모델 요청/응답·검증·사용량은 기존 artifacts에 보존한다. 공개 응답의 `companyOutlooks`는 DB 스냅샷 그대로 복원한다. 기존 공개 문서 접근/권한 검사를 유지하며 새 근거는 이미 허용된 공개 references의 부분집합이어야 한다. 과거 응답에는 이 필드가 없을 수 있다.

## 화면

모바일 간단히와 기존 전체 보기에 기업 전망을 먼저 표시한다. 사실·사업 영향·반대 요인과 문장별 근거 인용/원문 링크를 펼칠 수 있다. 같은 문서의 두 인용은 독립 기사 두 건으로 세지 않고 인용 수와 원문 수를 구분한다. 기존 시장 요약·KOSPI·KOSDAQ·환율·핵심 이슈·평가·정정은 유지한다.

## 실행 원칙

기본은 offline 계획이다. `--execute`·기존 키 파일·별도 출력 경로·사용자 실행 근거와 호출 상한을 명시해야 실제 모델을 호출한다. 프로세스 잠금과 불변 write-ahead 요청/사용량 원장을 사용하며 미응답 요청은 재전송하지 않는다. 완성된 실행은 입력 bundle 해시를 확인하고 0회 호출로 재사용한다. 새 입력/프롬프트 실행은 새로운 출력 경로를 사용한다. 과거 시뮬레이션은 당시 수집·본문 동일성이나 예측 적중을 입증하지 않는다.
