# 회차에 고정된 브리핑 상세·근거·시장 정보 (BRF-DEV-081)

D-BRF-01/02의 핵심 이슈에서 **자세히 보기**와 **근거 보기**를 연다.
선정 이유는 편집 판단이며 사실 근거인 직접 인용과 별도로 표시한다.

`GET /api/v1/briefings/{roundId}/items/{eventId}`는 발행 스냅샷의 항목만
반환한다. 원문 제목·매체·시각·버전·직접 인용·주변 본문·원문 링크를
제공하며 현재 문서 최신 버전으로 교체하지 않는다. 원문 링크의 외부
페이지는 이후 수정될 수 있으므로 저장한 인용·본문과 구분한다.
`bodyContext`의 모든 위치는 원문 전체 기준 Unicode code point이며 끝
위치는 포함하지 않는다. 조회 시 회차 가용성, 현재 권한, 고정 버전,
근거 참조, 원문 SHA와 정확한 인용 구간을 다시 검사한다.

문서 분석의 기존 `/api/v1/evidence/{id}` 계약과 검증은 유지한다.
이 API를 느슨하게 변경해 브리핑 인용을 끼워 넣지 않는다.

개발 재생은 `scripts/briefing_presentation_enrichment.py`로 별도 출력에
`presentationEnrichment`를 더한다. 원래 `briefingRecovery`와 그 원본
bundle·완료/미응답 호출 기록을 그대로 검증한 **후** 표시 데이터를
등록한다. 기존 DB를 갱신하는 migration이나 운영 발행 작업이 아니다.

- 동일 회차의 KOSPI/KOSDAQ은 확정 가능한 직전 거래일 종가를 사용한다.
  09:20 회차에 당일 장 마감 값을 넣지 않는다.
- 원/달러는 은행 일별 고시 기준환율이다. 고시 시각이 없으므로 전날까지
  확인 가능한 값만 쓰며 외환시장 종가·실시간 값으로 표시하지 않는다.
- 보존한 원 공급원 응답과 정규화·회차 cutoff를 재검증하며 새 HTTP나
  유료 AI 호출 없이 재생한다.
- `verified_issue_claims_and_indicators_v1` 요약은 이미 검증된 해당 회차
  이슈 문장을 그대로 재사용하고 검증된 지표 문장을 결합한다. 별도
  AI 생성·검증 성공이나 전체 적격 기업·업종 분석으로 주장하지 않는다.
  생성 방식·근거 문장별 참조·지표 참조는 스냅샷 계보에 보존하고
  요약 본문에도 범위를 표시한다.
- 새로운 전망, 종목 추천, 뉴스와 지수의 인과관계, 전망 적중률은
  생성하지 않는다. 넓은 기업 맥락을 다시 분석하는 시장 요약은 별도
  입력 고정과 생성·검증 과정이 필요하다.

출근은 `previousComparison`으로 직전 발행 브리핑의 핵심 이슈 구성을
비교하고, 퇴근은 `sinceMorning`으로 같은 날 출근 발행본과 비교한다.
신규·이어짐·빠짐은 저장한 eventId 집합의 차이이며 중요도 상승·하락,
사건 해소나 주가 변동의 의미가 아니다. 이전 문서의 권한 철회도
비교 내용 공개에 적용한다. 이전 전망의 성과 입력이 없으면 평가하지
않았다는 안내를 유지한다.

이번 변경에 ‘중요한 새 이슈가 없는 날 이전 뉴스를 재강조하여 정상
발행’ 정책은 포함하지 않는다. 원 PoC의 추출·사건 묶음 로직도 바꾸지 않는다.
