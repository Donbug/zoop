# 기업 로고 출처와 사용 조건

이 폴더의 SVG(`samsung`, `nvidia`, `intel`, `google`, `apple`, `meta`, `pinterest`, `dell`, `fujitsu`, `amd`, `arm`, `qualcomm`, `broadcom`, `cisco`, `tesla`, `supermicro`, `hyundai`, `kia`, `lg`, `naver`, `generalmotors`, `uber`, `palantir`, `snowflake`, `netapp`, `cloudflare`, `paloaltonetworks`)는 [Simple Icons](https://github.com/simple-icons/simple-icons)의 `simple-icons` npm 패키지(16.33.0)에 포함된 SVG를 수정 없이 복사했습니다. [패키지 원본 라이선스](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md)에 따라 아이콘 도형 데이터는 CC0 1.0입니다.

색상은 같은 패키지의 `data/simple-icons.json`에 기재된 각 아이콘의 `hex` 값이며, 항목별 브랜드 출처 URL은 `prototype/bff/fixtures/poc-real-companies.json`의 `brand_source`에 기록했습니다. `lg.svg`는 LG전자(`KRX:066570`)에만, `hyundai.svg`는 현대자동차에만 연결했습니다(같은 그룹의 다른 계열사에는 쓰지 않았습니다). 패키지에 아이콘이 없는 기업(예: SK하이닉스·Amazon·Microsoft·Micron·TSMC·IBM·CrowdStrike)에는 임의 이미지를 만들지 않고 화면의 모노그램 표지를 그대로 씁니다. 로고·회사명 등 상표권은 각 권리자에게 있으며 CC0가 상표 사용 허가를 뜻하지 않습니다. 이 파일들은 줍 관계 그래프 **시연 목적**으로만 사용합니다.
