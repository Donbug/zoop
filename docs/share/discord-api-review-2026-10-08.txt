**첨부 파일은 최종 확정본이 아니라 검토본입니다.** 특정 작성자의 수정 때문에 문제가 생겼다는 뜻은 아니며, 문서의 목표와 실제 구현 상태를 구분해서 봐주시면 됩니다.

**1. 수정본에 반영한 내용**
• 기업 상세 정보 6개 항목, 기업별 사건의 다중 관계, 최신 시세 조회 조건, Google/Kakao 제공자 지정을 목표 API에 반영했습니다.
• API–WBS 연결은 현재 업무명과 기능 의미를 기준으로 맞췄고, 기존 문서 요약·검증 상태·출처 정보는 유지했습니다.
• 로그아웃 보호 규칙과 일부 오류 응답 등도 정리했습니다. 추가 정정안은 팀 합의 완료 사항과 구분해 두었습니다.

**2. 명세 반영과 실제 구현은 별개입니다**
기업 정보의 추가 필드, 다중 사건 관계, 튜토리얼 상태 등은 프로토타입에 남은 구현 차이가 있습니다. 소셜 로그인도 목표는 Google/Kakao지만 현재 동작은 모의 로그인입니다. 수정본을 해당 기능의 구현 완료 보고로 보시면 안 됩니다.

**3. 담당별로 확인 부탁드리는 부분**
• **기능명세·WBS 담당:** FS042가 재무와 시점 그래프에 함께 쓰이는 부분, AI 구/v2의 기능 번호 이동, 파이프라인 번호·역할·일정 불일치를 확인 부탁드립니다. 기능을 삭제하거나 번호를 일괄 치환하지 않고 실제 의미에 맞춰 정리하려고 합니다.
• **관련 FE·BE 담당:** 담당 API의 요청·응답과 화면 동작을 확인 부탁드립니다. 특히 튜토리얼의 비회원 무저장/회원 완료·건너뛰기 구분, 관리자 동시 수정 방지, 사건 목록 페이지 처리, AI 작업의 중복 요청 규칙을 맞춰야 합니다.
• **함께 결정할 내용:** 1년 주가 차트의 주/월 단위와 기존 계정–소셜 계정 연결 정책 등입니다. 기술 세부사항은 담당자가 처리안을 제안하고 API 명세에 명시하면 좋겠습니다.
