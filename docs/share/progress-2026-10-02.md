## 2. 현재 상태

- **명세 v1.2 대조**(93개): 구현 51 · 부분 36 · 충돌 2 · 미구현 2 · 데이터 없음 2. 처음 대조했을 때는 구현 17·충돌 10이었다. 남은 「부분」의 대부분은 1번 표의 결정이나 아래 데이터 공백에 막혀 있다.
- **시연 데이터**: 실제 기업 발표·공시 기사 39건을 판정했고(모델 호출 1,971회, 승인된 예산 2,000회 이내), 지도에는 기업 26곳·사건 138건·연결선 170개가 나온다. 출처는 NVIDIA·삼성전자·SK하이닉스 뉴스룸, OpenDART, 미국 연방관보다. 이용할 수 있는 출처 사정으로 기술 업종에 쏠려 있다.
- **구현된 화면**: 시작·가입·온보딩·5단계 튜토리얼, 메인 지도(전체/개인화, 영향 경로, 두 기업 경로, 포커스, 미니맵), 기업 상세(시세·주요 지표·차트·사건 타임라인·문서·보유 평가), 출퇴근 브리핑(회차별 발행·정정, 발행 당시 그래프), AI 질문(작업 단위 저장·결과 회수, 규칙 기반 답변), 관리자 패널(관제·검수·그래프 버전·작업·AI 사용량·브리핑 운영·통계·선호도·회원 관리).
- **품질 확인**: BFF 테스트 270개, 웹 자동 테스트 41개, 빌드, 슬롭 검사 0건. 바뀐 화면은 1440/390px × 라이트/다크에서 접근성 위반 0건이다.
- **그래프 가독성**: 1440px 화면에서 지도 면적이 40%에서 80%로 늘었다. 기업 이름표 겹침은 0건이 됐고, 확대·이동이 끊기던 문제를 해결했다(프레임 간격 p95 175ms → 16.7ms).

## 3. 데이터·외부 연동이 없어 만들지 않은 것

시장 요약·시장 변수(브리핑), 재무·실적 추이, 생성형 AI 답변, 뉴스 요약, 산업·테마 분류, 실제 소셜 로그인 제공자, 05·35분 정기 뉴스 수집원. 화면은 이런 값을 지어내지 않고 자리를 숨기거나 「미제공」으로 표시한다.

## 4. 실행과 저장소

- 저장소: [Donbug/zoop](https://github.com/Donbug/zoop)(문서·프로토타입), [Donbug/investmate-poc](https://github.com/Donbug/investmate-poc)(PoC). 둘 다 비공개다. 처음 받을 때는 `gh auth setup-git`을 한 번 실행한다.
- 실행 방법: [prototype/README.md](../../prototype/README.md). 데모 회원 `demo@zoop.local` / `zoop-demo`, 관리자 `/admin`에서 `admin@zoop.local` / `zoop-admin`.
- 관리자 원장 화면을 쓰려면 Docker `zoop-poc` 컨테이너(Postgres·Neo4j)가 필요하다. 사용자 지도는 저장소에 든 스냅샷만으로 동작한다.

## 5. 다음 후보 (결정 후)

1. 1–3번 결정에 맞춰 관리자 재검증 흐름과 대화록 열람 권한을 구현한다.
2. WBS 일정에 맞춰 남은 「부분」 항목의 우선순위를 다시 잡는다.
3. 예산이 확보되면 OpenDART 공시로 여러 산업을 수집하고, 공시의 업종 분류로 산업군 묶기를 시도한다.
4. 그래프 가독성 남은 과제를 진행한다. 300노드 첫 화면 전략(R2)과 사용자 테스트(R3)가 남았다.
