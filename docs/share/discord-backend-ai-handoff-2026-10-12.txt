@everyone 백엔드 연동 작업 공유드립니다. 팀에서 올려주신 Spring 기반에 AI 연동 코드를 통합해 main에 반영했습니다. 다음 작업 전에 최신 main을 받아 주세요.

**이번에 반영한 내용**
- 본개발용 AI 코드를 `ai/worker`, `ai/pipeline`, `ai/service`로 분리했습니다. 본개발 코드가 프로토타입 소스를 가져다 쓰지 않는 구조입니다.
- Spring에 `AiAnalysisClient`를 추가했습니다. AI 작업 제출·상태 조회·결과 조회·취소·복구를 지원합니다.
- 문서 요약·기업 관점 긍정/부정·의미 검증·브리핑 전망의 4가지 작업에 대해 실제 Java → Python 서비스 → AI worker 연결을 검사했습니다. 외부 유료 모델 대신 재현용 입력을 사용했으므로, 실제 모델 품질 검증이나 운영 배포가 완료됐다는 뜻은 아닙니다.
- 기존 백엔드 공통 오류 처리와 요청 ID 필터는 유지했습니다. AI 내부 API는 별도 계약이며, 공개 `/api/v1`을 대체하지 않습니다.

**백엔드에서 이어 붙일 부분**
현재 완료된 것은 AI 호출 계층입니다. 공개 API·인증·DB 저장까지 자동으로 연결된 상태는 아닙니다.
- `jobId`를 요청한 사용자·문서·브리핑 회차와 연결하고 조회 권한을 확인해야 합니다.
- 결과를 저장하기 전에 원본 문서 버전·인용 근거·현재 이용 권한을 확인하고, 서비스 DB에 트랜잭션으로 반영해야 합니다.
- AI 내부 오류 코드는 공개 API의 오류 규칙으로 변환해야 합니다.
- HTTP `202`는 접수, `READY`는 AI 결과 준비를 뜻합니다. 사용자 공개 완료와는 다르며, `WITHHELD` 결과는 본문을 제공하지 않습니다.
- 제출 중 타임아웃이나 503이 발생하면 새 작업을 바로 만들지 말고 기존 `jobId`의 상태부터 확인해 주세요. 재시도는 같은 `jobId`·같은 요청 내용으로 처리해야 합니다.

**설정·검사·문서**
AI 클라이언트는 기본 비활성입니다. 활성화에 필요한 환경변수와 내부 API 주소·인증 설정은 아래 연동 문서에 정리했습니다. 실제 토큰이나 `.env`는 Git·디스코드에 올리지 말아 주세요.
