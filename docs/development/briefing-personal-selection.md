# 보유·관심 종목 개인화 브리핑 (FS036 / D-BRF-01·02)

`GET /api/v1/briefings/{id}/personalized/issues`는 회원 본인 세션에서만 조회합니다. 기존 공통 발행 원문·시세·상세·평가를 바꾸지 않고 별도의 선정 결과를 제공합니다. `/briefing?view=personal`에서 확인합니다. 종목이나 회원 ID를 요청 파라미터로 받지 않습니다.

- 현재 연결한 모의 계좌의 보유 종목과 DB 관심 종목을 합칩니다. 실계좌 보유로 표시하지 않으며 시세 평가·비중 계산을 호출하지 않습니다.
- 공통 발행의 3개가 아니라 **회차 전체 후보 원장**을 조회합니다. 근거·회차 마감·중요도 2 이상·새 사건/중요한 변경·확인된 기업 연결을 유지합니다.
- 사업 중요도 → 정보 변화 → 관련 기업 수 → 사건 ID의 결정적 순서입니다. 주가 미관측을 0점으로 쓰지 않으며, 종목별 개수 제한은 없습니다. 같은 사건 키와 동일 문서·버전·정확 인용의 중복 추출은 제외합니다. 사건 키의 의미적 통합은 상류 사건 묶음의 책임이며 제목을 번역해 새 사건으로 만들지 않습니다.
- 현재 원문 접근 상태·정확 본문 버전·발행 시각·최신 권한을 다시 검증합니다. 권한이 불명확한 후보는 다음 적격 후보로 넘깁니다. DB/권한 원장 장애를 ‘새 소식 없음’으로 바꾸지 않습니다.
- 새로 선정된 후보의 기존 상세 AI 결과가 없으면 검증된 사실·선정 이유·기업 연결·정확 인용/출처만 제공하고 분석 미저장을 알립니다. 읽기 중 AI 호출은 없습니다.
- 이전 이슈는 고정된 직전 회차의 같은 이슈+기업 기준입니다. 새 핵심 목록에 없다고 확인 과제를 완료 처리하지 않습니다. 현재 종목으로 직전 원장을 재현한 추적이며, 과거 사용자의 실제 열람 이력을 뜻하지 않습니다. 후속 자료 부재와 조건 충족을 구분합니다.

## 저장/입력

후속 migration `V20261030110000`의 `briefing_personal_pools`는 공통 회차 FK와 원문 SHA를 갖는 불변 입력입니다. 기존 publication/feedback 테이블을 갱신하지 않습니다. 후보 저장본이 없으면 `pool_unavailable`이며 공통 3개로 조용히 대체하지 않습니다. 운영 생성기는 회차 후보의 평가·독립 검증이 완료되면 이 원장에도 전체 입력을 등록해야 합니다. 이 PR은 기존 완료 영수증의 오프라인 등록기를 포함합니다.

```sh
python scripts/briefing_personal_pool.py \
  --prepared /private/recorded/prepared \
  --executed /private/recorded/executed \
  --registry /private/article-version-grant-bindings.json \
  --output /private/new-personal-pools
# 검토한 SQL을 해당 원본이 있는 전용 개발 DB에 적용한다. 원문/권한/결과/쿠키 파일은 커밋하지 않는다.
psql "$PERSONAL_DATABASE_URL" -v ON_ERROR_STOP=1 -f /private/new-personal-pools/2026-10-22-morning.sql
```

`registry`는 기존 원문 레지스트리의 `{documentId,documentVersion,bodySha256,grantId,grantRevision,recipients}` 배열입니다. 생성·독립 검증 요청/응답 SHA와 동결 입력의 정확한 결속을 확인한 기존 후보만 옮깁니다. 미등록 원문은 전체 후보 원장에 남기되 현재 권한 검증에서 제외됩니다. 등록기는 새 AI 요청·원문 재수집을 하지 않습니다. 동일 입력 재적용은 기존 행을 보존하며 다른 내용으로 덮어쓰지 못합니다.

## 검증

- Java 정책 회귀: 전체 후보에서 선정, 같은 기업의 독립 사건 3개, 동일 사건/인용 중복, 중요도·재보도·미확인 연결·미래 자료 제외.
- PostgreSQL/HTTP: 실제 세션·DB 관심 종목·전체 후보 선정·타 회원 ID 위조 무효·원문 권한 철회·불변 원문 SHA 보존.
- UI: 관련 이유·저장 근거·이전 추적, 없는 저장본/종목/관련 이슈, 장애 재시도, 계정 변경과 늦게 도착한 응답 격리.
- 기존 4회차 완료 자료는 별도 DB에서 재사용해 확인합니다. 실제 뉴스·평가 결과·계정/키는 이 PR에 포함하지 않습니다.
