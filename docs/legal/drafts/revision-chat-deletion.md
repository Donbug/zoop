# 개정 초안: 대화별 삭제 (처리방침·이용약관 2026-10-13.1 → 다음 버전)

상태: **초안, 팀 승인 전. 공개·`term_versions` 등록 금지.** 작성 2026-10-27.

## 1. 왜 바꾸나

승인·시행 중인 개인정보 처리방침과 이용약관(`2026-10-13.1`)은 "개별 채팅을 삭제하는 화면 기능은 제공하지 않는다"고 고지한다. 앱에는 회원이 대화를 하나씩 즉시 삭제하는 기능(`deleteConversation`, D-AI-02 대화 기록)이 구현돼 있지만, 이 고지와 어긋나므로 서버 설정 `zoop.chat.delete-enabled=false`로 꺼 두었다. 이 개정본이 승인되고 시행되면 설정을 켠다.

삭제 동작(구현 기준):

- 회원이 고른 대화의 질문·답변·고정 문맥·처리 상태·도구 호출 기록을 즉시 삭제한다. 삭제 표시나 보관 기간은 없다.
- 처리 중인 질문이 있는 대화는 삭제하지 않는다(먼저 취소).
- 답변 생성에 쓴 모델 실행 원장(`ai_executions`)의 단계·모델·토큰 수·비용·시각은 대화·회원과 연결을 끊고 남는다. 질문·답변·회원 ID는 들어 있지 않다.
- OpenAI 측 기록(남용 감시 로그 최대 30일 등)은 앱의 삭제로 지워지지 않는다. 기존 처리방침 3항과 같다.
- 회원 탈퇴 시 모든 대화를 일괄 삭제하는 것은 그대로다. 2026-10-27에 모델 실행 원장이 탈퇴(회원 삭제)를 막던 결함(`V20261027120000`)을 고쳤다.

## 2. 문장 변경안

### 개인정보 처리방침

보유 기간 문단(승인본 25행):

- 현행: "개별 채팅을 삭제하는 화면 기능은 제공하지 않으며, 탈퇴 시 모든 대화 내역을 일괄 파기합니다."
- 변경: "이용자는 AI 질문 창의 '대화 기록'에서 대화를 하나씩 삭제할 수 있으며, 삭제한 대화의 질문·답변과 처리 기록은 즉시 파기합니다. 처리 중인 질문이 있는 대화는 질문을 취소하거나 처리가 끝난 뒤 삭제할 수 있습니다. 탈퇴 시에는 모든 대화 내역을 일괄 파기합니다. 답변 생성에 사용한 모델 이름·토큰 수·비용 같은 운영 통계는 대화와 회원을 알 수 없는 형태로 남을 수 있습니다."

권리 행사 문단(승인본 46행):

- 현행: "개별 채팅 삭제 화면은 제공하지 않지만, 개인정보 삭제 요청은 이 연락처로 접수합니다. 회원 탈퇴 시 대화 전체를 일괄 삭제합니다."
- 변경: "대화 내역은 AI 질문 창의 '대화 기록'에서 직접 삭제할 수 있고, 그 밖의 개인정보 삭제 요청은 이 연락처로 접수합니다. 회원 탈퇴 시 대화 전체를 일괄 삭제합니다. 외부 AI 제공자가 보관하는 기록은 3항에 따릅니다."

### 서비스 이용약관

탈퇴 조항 2항(승인본 43행):

- 현행: "개별 채팅 삭제 기능은 제공하지 않으며, 회원 탈퇴 시 운영자 측 대화 내역·활동 기록·계정 정보·약관 동의 이력을 즉시 파기합니다."
- 변경: "이용자는 대화를 하나씩 삭제할 수 있으며, 회원 탈퇴 시 운영자 측 대화 내역·활동 기록·계정 정보·약관 동의 이력을 즉시 파기합니다."

## 3. 시행 절차

1. 팀이 문장을 승인한다. 다시 동의를 받아야 하는지(이용자 권리를 넓히는 변경이라 고지로 충분한지)를 함께 정한다.
2. `approved/`에 새 버전 문서(예: `2026-10-XX.1`)를 만들고, 새 Flyway migration으로 `term_versions`에 등록하며 이전 버전의 효력 종료 시각을 같은 트랜잭션에서 조정한다(`docs/legal/README.md`). 기존 migration과 승인 문서는 고치지 않는다.
3. 시행 시각 이후 배포 환경에서 `ZOOP_CHAT_DELETE_ENABLED=true`(`zoop.chat.delete-enabled`)로 켠다. 웹은 `listConversations`의 `deleteEnabled`로만 삭제를 보여 주므로 웹 배포는 따로 필요 없다.
4. `drafts/privacy-policy.md`·`drafts/terms-of-service.md`·`drafts/README.md`의 "개별 채팅 삭제 없음" 문구는 이 개정이 승인될 때 함께 정리한다.

## 4. 확인 필요

- 재동의 필요 여부와 고지 방법·기간.
- 운영 통계(모델 실행 원장)를 "개인정보가 아닌 운영 통계"로 남기는 문구가 충분한지.
- 대화 목록 화면은 와이어프레임에 없어 D-AI-02 드로어 안의 '대화 기록' 보기로 임시 구현했다. 화면 설계를 확정하면 문구의 화면 이름도 맞춘다.
