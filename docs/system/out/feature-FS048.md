## 상세 권한과 의미 이행

- 이 번호의 옛 AI 탭 정의는 현재 FS047로 이행된다(다른 번호로 이동). 보존: 현재 권한과 지정 문서·버전 유지, 과거 asOf 이후 공개 문서 제외, 조건 부족·근거 부족·기술 장애 구분, 지정 버전을 최신으로 대체 금지, 안내 결과 저장 후 같은 작업 재평가 금지.
- 옛 FS049 답변 검증과 제공에서 이행됨(다른 번호로 이동). 보존: 인용·원문 구간·그래프 참조 검증, 현재 유효 실행만 저장, 저장 후 완료, 검증 실패의 자동 재생성 금지, 보존 결과는 모델 재호출 없는 저장 복구.

문서 판정 출처: 옛 FS049 [docs/evidence/spec-v1.2-gap.md:42 (text-line)](../../../docs/evidence/spec-v1.2-gap.md). 기준선에 반영 현황의 마지막 행을 적용한 판정이며 번호가 재사용된 AI ID는 의미 이행표가 정한 곳에만 적용한다. 이번 생성기의 실행 검증은 아니다.
