## 상세 권한과 의미 이행

- 옛 FS046 AI 권한과 중복 작업 통제에서 이행됨(단일 신규 ID 없음 · 서버 공통 의무로 분산 보존). 보존: 로그인·대화 소유권·근거 접근 권한 재검증, 같은 작업 ID의 내용 불일치 거절, 같은 대화에 서로 다른 작업 ID가 동시에 와도 유효 실행 하나, 상태 조회·결과 회수는 신규 접수와 구분. 버튼 비활성화만으로 대체하지 않는다. 공통 규칙 aiJobs·idempotency와 NFS001/003이 서버 계약으로 유지한다.
- 이 번호의 옛 AI 탭 정의는 현재 FS046로 이행된다(다른 번호로 이동). 보존: 최초 질문 시각·맥락·대상·실제 기간 고정, 명시 조건 우선, KST 작년=직전 달력 연도·최근=기본 1개월, 되묻기 저장 완료, 보충 입력은 새 작업.
- 옛 FS048 개인화 조건과 근거 확보에서 이행됨(다른 번호로 이동). 보존: 현재 권한과 지정 문서·버전 유지, 과거 asOf 이후 공개 문서 제외, 조건 부족·근거 부족·기술 장애 구분, 지정 버전을 최신으로 대체 금지, 안내 결과 저장 후 같은 작업 재평가 금지.

문서 판정 출처: 옛 FS048 [docs/evidence/spec-v1.2-gap.md:41 (text-line)](../../../docs/evidence/spec-v1.2-gap.md). 기준선에 반영 현황의 마지막 행을 적용한 판정이며 번호가 재사용된 AI ID는 의미 이행표가 정한 곳에만 적용한다. 이번 생성기의 실행 검증은 아니다.
