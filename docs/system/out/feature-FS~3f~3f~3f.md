## 확인 필요

- SPEC_NOT_IN_INDEX: 상세 시트에만 있는 ID를 원문 그대로 보존했다.
- MALFORMED_SPEC_ID: 명세 ID 형식 오류. 번호를 추정하거나 고치지 않는다.
- CONTRACT_UNDECIDED: 브리핑 목록·검색 상세의 잘못된 원본 ID다. 팀 정정 전 명세 번호를 추정하거나 부여하지 않는다. 기존 회차/목록 API 연결과 구분한다.
