- 원문 기능 ID 셀은 정정되지 않았다. 제목 행에 근거해 FS066-01에 유효 연결한다. 원문 기능 ID 셀은 오류로 보존한다. 제목 행과 목차 FS066-01 통합 선언에 근거한 유효 연결만 별도로 기록하며 원문 오류가 해소됐다고 보고하지 않는다.

## 확인 필요

- SPEC_NOT_IN_INDEX: 상세 시트에만 있는 ID를 원문 그대로 보존했다.
- MALFORMED_SPEC_ID: 명세 ID 형식 오류. 번호를 추정하거나 고치지 않는다.
- RAW_ID_CORRECTION: 원문 기능 ID 셀(05-출퇴근-브리핑.csv 134행)은 정정되지 않았다. 제목 행(132행)과 목차 통합 선언에 근거해 FS066-01에 유효 연결만 기록한다.
