## 확인 필요

- SPEC_NOT_IN_INDEX: 상세 시트에만 있는 ID를 원문 그대로 보존했다.
- MALFORMED_SPEC_ID: 명세 ID 형식 오류. 번호를 추정하거나 고치지 않는다.
- CONTRACT_UNDECIDED: 재무 상세 행의 잘못된 원본 ID다. FS042로 추정 치환하지 않는다. 목표 재무 API는 목차 FS042에 연결했다.
