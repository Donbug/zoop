## 결론

**WBS는 새 고정본을 사용하고 기능·비기능 명세는 기존 고정본을 유지한다.** 15:05 KST 전셀 비교에서 WBS 계산값 11셀·수식 원문 34셀 변화가 확인됐다. 명세 15개 탭은 셀값·수식·순서·범위가 모두 동일하다. WBS ID·업무명·BE/FE 역할은 바뀌지 않았고, FS 의미 연결 변경은 `6.8.14`의 **FS037→FS066-01** 정정 하나다.

팀원 Markdown의 네 변경 의도와 구 번호 체계는 분리해야 한다. 현재 `6.10.1`은 관리자 인증이고 API 통합은 `6.11.1`이다. 번호 존재만으로 연결을 유지하거나 전역 치환하지 않는다. 원문 `검토 전`은 보존하되 [오늘 사용자 결정](../share/day-work-2026-10-08.md)에 따라 전체 명세/WBS를 설계·구현 계획에 포함한다. 원문 진척률·합의 표시는 API 실행이나 수용 기준 통과 증거가 아니다.
