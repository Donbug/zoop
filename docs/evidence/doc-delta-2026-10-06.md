# 팀 문서 재수집·변경 전수 대조 (2026-10-06)

## 1. 결론과 수집 범위

- 기능·비기능 명세는 **15시트 유지, 12셀의 복사 머리글 제거만 있음**이다. FS/NFS 상세 필드의 실질적 기능 변경은 없다. `메인그래프 v2`·`AI 챗봇 v2`와 기존 시트가 계속 병존하며 대체 선언은 없다.
- 요구사항 정의서는 10-01의 82레코드에서 **85레코드**로 늘었다. 새 요구 26·27·37이 추가되고 이후 번호가 이동했다. 기존 AI 답변 검증의 잘못된 중복 번호 `9`가 `49`로 복구됐다. 번호를 기능 의미로 쓰면 안 된다. 같은 기능명/설명으로 대조한 뒤 번호 변경과 내용 변경을 따로 기록했다.
- WBS는 **내용 동일**이다. xlsx 컨테이너 sha256은 다르지만 `data_only=True`로 읽은 모든 셀·시트명·순서·범위가 직전 고정본과 같다. 새 WBS 폴더를 만들지 않았다. 담당 배정과 일정 변경도 없다.
- Notion은 **120→121페이지**, 신규 빈 회의록 1개, 기존 본문 변경 2개, 삭제 0개다. 기존 FE2/BE2 역할안이 `역할 배정`에서 `휴지통`으로 옮겨졌고 현재 역할 페이지에는 BE3안만 남는다. 기업 상세/타임라인/수집 API의 경계 메모가 추가됐지만 실명 배정과 구체 API 규격은 없다.
- 새로 활성 링크된 구글 시트·문서·드라이브·Figma 문서는 **없음**이다. CRDT 삭제 이력의 과거 URL은 현재 본문의 새 링크로 세지 않았다. 공개 루트 밖의 문서와 외부 ClovaNote 본문은 수집 범위가 아니다.
- 프로토타입 코드, 기존 원본, 화면계획서 파일은 수정하지 않았다. 팀 승인 상태를 임의로 올리거나 새 API 계약을 만들지 않았다.
