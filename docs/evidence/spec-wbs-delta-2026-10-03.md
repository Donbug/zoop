# 10-03 갱신 명세·WBS 차이 정리

## 1. 결론과 증거 범위

- 프로토타입 코드는 변경하지 않았다. 새 원본을 날짜별 폴더에 보존하고 README 원본 목록만 추가했다. 기능 기준 문구의 채택 판단은 Main에 남긴다.
- 명세는 13→15시트다. 기존 13시트 중 10시트가 변경됐고, 동일 ID의 상세 레코드 60개가 달라졌다(기능 49개·비기능 11개). 기존 시트의 상세 ID 레코드는 93→95개이며 새 v2 시트를 중복 합산하지 않았다. 목차는 93→94행이므로 목차와 본문은 이미 불일치한다.
- 새 `메인그래프 v2`와 `AI 챗봇 v2`는 기존 시트와 **병존하는 개정안**이다. 일부 `확정` 표기는 있으나 전면 대체 선언은 없다. 이를 전부 미승인 초안이나 전부 확정 정본으로 묶으면 원문을 왜곡한다.
- `변경 내역`과 `제안·확인 사항`에는 새 항목이 없다. 기존 D01–D12도 그대로다. 상세 내용이 대폭 바뀌었지만 변경 관리 시트는 갱신되지 않았다.
- 새 WBS v0.2는 과거 완료 내역을 반영하고 73개 기능 단위 개발을 새로 계획한다. **개발 작업의 수행인력은 전부 공란**, 개발 진척률은 0%다. UI·UX 설계만 네 명의 이름이 있다. 현재 프로토타입의 재사용/참고 여부는 언급하지 않는다.
- WBS 본표와 일정 요약의 날짜가 여러 영역에서 다르다. 그래프 Alpha·동결·통합 마일스톤과 실제 작업 종료일도 충돌한다.

## 3. v2 시트 분석

### 3.1 상태·작성자·대체 여부

- 두 v2 시트 모두 머리글은 `상세형 v1.2`이며 제안은 원본 승인 상태와 구분하고 수용 기준은 테스트 통과 결과가 아니라는 문구를 유지한다(각 시트 행 2–4). 시트 본문에 작성자·개정일·기존 시트 폐기/대체 선언은 없다.
- 그래프 v2는 기존과 같은 FS017–FS027 11개다. FS017–FS021·FS024·FS026의 내용이 달라지고 FS022·FS023·FS025·FS027은 동일하다. 일부 원본 상태 행이 `원본 우선순위` 또는 `항목`으로 바뀌어 상태값이 사라졌다. FS022는 여전히 검토 중, 신규 동작은 제안 기준이며 원본 승인/구현 상태를 바꾼 것이 아니라고 적는다(행 79,92).
- AI v2의 실제 상세 블록은 FS045–FS051 **7개**인데 머리글은 11개로 남는다. 대부분 `팀 검토 전`; FS049는 `v1.3: MVP 기준 확정`, FS051은 `원본 상태: 확정`이다(행 64,93). 여러 버전·승인 표기가 혼재한다.
- [추론] WBS의 AI 기능명이 v2와 같고 FS052/FS053을 FS051 내부 처리로 묶어 둔 점은 v2로 단순화하려는 의도를 뒷받침한다. 그러나 AI 기존 시트와 목차가 남아 있어 전면 채택 근거는 아니다.
- Jev에 이 제한된 상태 표기만 대조했고 `mixed_parallel` 판단을 받았다. 이는 보조 판단이며 위 원문 검증을 대신하지 않는다.

## 9. 후속 Notion 교차 근거

NotionRefresh가 새 고정본을 공유한 뒤 해당 범위만 추가로 확인했다. 위 §3.1의 “전면 대체 선언 없음·상태 혼재”는 **xlsx 내부 표기**에 대한 판정이다. 회의 준비 문서에는 AI 개정안의 의도가 더 명시돼 있으므로 두 출처를 합칠 때 아래 사실을 반영해야 한다.

- `docs/evidence/raw/notion_2026-10-03/1002_데일리_스크럼_준비__73c38c4c.md:17-124`는 제목을 **AI 코파일럿 기능명세서 v1.3·7개 명세**라고 쓰고 FS045–FS051 모두에 `v1.3: MVP 기준 확정`을 붙인다. 내용과 최근 1개월·최대 2-hop·문장 사실성 P2·대화 목록 P2 정책이 xlsx `AI 챗봇 v2`와 대응한다. - 같은 문서 `:126-138`에는 xlsx 별도 시트에 없는 `NFR-AI-01` 근거성, `02` 금융 안전성, `03` 시간 정합성, `04` 개인정보, `05` 중복 방지가 P1로 명시된다. 복잡한 작업 ID 충돌·저장 복구 상태는 **별도 사용자 기능이 아닌 내부 구현**으로 분류한다. 따라서 AI v2에서 줄어든 세부 작업 정책을 제거한 것으로 해석하면 안 된다.
