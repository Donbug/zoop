#### 아이디어 1 : 금융 다마고치
<!-- block: 3d5fef49-d8d5-80b4-90d5-ecbf1d551e58; type: text -->
“계좌 거래내역으로 성장하는 금융 다마고치”로 발전시키면 꽤 강한 프로젝트가 됩니다. 캐릭터와의 대화, 소비 분석, 금융상품 추천이 하나의 경험으로 자연스럽게 연결돼요.

<!-- block: 3d5fef49-d8d5-80be-89a6-de4adef40e43; type: text -->
다만 핵심은 캐릭터를 단순한 장식이 아니라 사용자의 금융 상태를 시각화하는 인터페이스로 만드는 것입니다.

<!-- block: 3d5fef49-d8d5-805d-b4b3-d62cffb74170; type: sub_header -->
### 핵심 사용자 흐름

<!-- block: 3d5fef49-d8d5-807c-a7e0-effd64ae4215; type: code -->
```plain text
계좌 연동
  ↓
거래내역 자동 수집·분류
  ↓
소비 습관과 금융 상태 분석
  ↓
캐릭터 상태 및 개인 퀘스트 생성
  ↓
캐릭터와 대화하며 원인·해결책 확인
  ↓
실제 행동 변화
  ↓
캐릭터 성장
```

<!-- block: 3d5fef49-d8d5-8025-bee9-dd47a834b26f; type: text -->
예를 들어:

<!-- block: 3d5fef49-d8d5-80fe-9009-edaba5861c01; type: bulleted_list -->
- 배달 지출이 평소보다 40% 증가→ 캐릭터가 지치는 것이 아니라 “배달 몬스터 출현”

<!-- block: 3d5fef49-d8d5-800d-9077-f1c18754b947; type: bulleted_list -->
- 이번 주 예산을 지킴→ 몬스터 처치, 경험치 획득

<!-- block: 3d5fef49-d8d5-808c-ba34-e76e41e5ed6a; type: bulleted_list -->
- 자동이체 저축을 실행→ 캐릭터 집이나 마을이 성장

<!-- block: 3d5fef49-d8d5-8065-8b78-f712bbb7eb56; type: bulleted_list -->
- 사용하지 않는 구독을 해지→ 매달 생산되는 골드 증가

<!-- block: 3d5fef49-d8d5-800f-b3d0-c6669f0d0078; type: bulleted_list -->
- 비상금 목표 달성→ 새로운 지역 개방

<!-- block: 3d5fef49-d8d5-804c-935f-e5aa4e2eac4f; type: text -->
이렇게 만들면 사용자가 돈이 적다고 불이익을 받는 게임이 아니라, 자신이 설정한 목표를 달성하면 성장하는 게임이 됩니다.

<!-- block: 3d5fef49-d8d5-8003-91e2-e8fc8365a874; type: sub_header -->
### 캐릭터와의 대화

<!-- block: 3d5fef49-d8d5-8006-83df-eda60bab9845; type: text -->
캐릭터는 일반적인 AI 챗봇이 아니라 사용자의 금융 데이터를 이해하는 동반자입니다.

<!-- block: 3d5fef49-d8d5-80fd-8fec-e3e7a8870e32; type: quote -->
사용자: 이번 달에 왜 돈이 부족해?

<!-- block: 3d5fef49-d8d5-80af-86d0-e42406b27c5d; type: quote -->
캐릭터: 지난달보다 배달비가 8만 4천 원 증가했고, 연간 구독료 6만 원이 결제됐어. 남은 고정비를 고려하면 이번 달 자유롭게 사용할 수 있는 돈은 약 12만 원이야.

<!-- block: 3d5fef49-d8d5-80a0-97ec-c99c10f19618; type: quote -->
사용자: 다음 달부터 20만 원씩 저축하려면?

<!-- block: 3d5fef49-d8d5-800a-be6d-c6daf3d7d59c; type: quote -->
캐릭터: 배달 횟수를 주 4회에서 2회로 줄이면 약 11만 원, 사용하지 않는 구독을 정리하면 3만 원을 확보할 수 있어. 부족한 6만 원을 다른 항목에서 찾아볼까?

<!-- block: 3d5fef49-d8d5-8096-ae14-c0e5bca97375; type: text -->
중요한 점은 AI가 답을 지어내지 않고, 먼저 분석 서버가 계산한 숫자를 받아 사람이 이해하기 쉽게 설명하도록 설계하는 것입니다.

<!-- block: 3d5fef49-d8d5-8011-bd0b-f0ef23c063de; type: sub_header -->
### 금융상품 추천도 가능하지만

<!-- block: 3d5fef49-d8d5-80e6-8fc8-d01e616250a4; type: text -->
가능합니다. 다만 처음부터 예금·카드·대출·투자를 전부 추천하면 범위가 너무 커집니다. MVP에서는 적금이나 예금 상품 하나에 집중하는 것이 좋습니다.

<!-- block: 3d5fef49-d8d5-8070-a2f3-ffc812ff029b; type: text -->
예를 들어 사용자가:

<!-- block: 3d5fef49-d8d5-804d-b403-ff37b7930250; type: quote -->
“6개월 뒤 여행비 120만 원을 모으고 싶어.”

<!-- block: 3d5fef49-d8d5-8067-bb2c-d9c6318a7c7a; type: text -->
라고 하면 시스템이:

<!-- block: 3d5fef49-d8d5-80d4-a13e-c9cf6f6ebb09; type: numbered_list -->
- 거래내역으로 월 저축 가능 금액 계산

<!-- block: 3d5fef49-d8d5-805c-a255-d2029601527a; type: numbered_list -->
- 월 20만 원 저축 목표 설정

<!-- block: 3d5fef49-d8d5-8011-887a-eecfdef55a68; type: numbered_list -->
- 조건에 맞는 적금 상품 필터링

<!-- block: 3d5fef49-d8d5-8048-8ba1-fb760f662124; type: numbered_list -->
- 금리뿐 아니라 중도해지, 가입 조건, 우대조건 비교

<!-- block: 3d5fef49-d8d5-80c6-b9f1-e03dbd90e505; type: numbered_list -->
- 추천 근거를 캐릭터가 설명

<!-- block: 3d5fef49-d8d5-80a4-9c54-f45bb26e01a9; type: text -->
하도록 만들 수 있습니다.

<!-- block: 3d5fef49-d8d5-801c-a561-e3d9752de149; type: text -->
단순히 “이 상품이 좋아요”라고 추천하면 안 되고 다음과 같이 근거를 보여주는 것이 중요합니다.

<!-- block: 3d5fef49-d8d5-8025-bf0e-c199dd50dbf3; type: quote -->
월 20만 원을 6개월간 납입할 수 있고, 급여이체 우대조건을 충족할 가능성이 있어 이 상품을 추천했어. 단, 중간에 해지하면 우대금리가 적용되지 않을 수 있어.

<!-- block: 3d5fef49-d8d5-807e-b472-e946819c3d8a; type: text -->
학교 프로젝트에서는 실제 금융 자문처럼 표현하기보다 상품 비교 및 정보 제공 서비스로 정의하는 편이 안전합니다.

<!-- block: 3d5fef49-d8d5-80d9-9e28-f140b0d1731d; type: sub_header -->
### 프로젝트의 기술적 강점

<!-- block: 3d5fef49-d8d5-808b-b85d-dd4b053c83db; type: bulleted_list -->
- 오픈뱅킹 API 또는 샌드박스를 통한 계좌 연동

<!-- block: 3d5fef49-d8d5-8043-a006-d20d00e56b79; type: bulleted_list -->
- 거래내역 자동 카테고리 분류

<!-- block: 3d5fef49-d8d5-80dd-be01-c70d32febccd; type: bulleted_list -->
- 사용자별 소비 패턴 및 이상 지출 탐지

<!-- block: 3d5fef49-d8d5-801e-abf6-c852a6346342; type: bulleted_list -->
- 목표 달성 가능성 예측

<!-- block: 3d5fef49-d8d5-80b8-b54a-ff968ed9c5ef; type: bulleted_list -->
- 개인화 퀘스트 추천 알고리즘

<!-- block: 3d5fef49-d8d5-80ae-8133-f041ea2b5f07; type: bulleted_list -->
- 금융상품 조건 기반 필터링 및 랭킹

<!-- block: 3d5fef49-d8d5-8074-9ce7-fe3d7541e6de; type: bulleted_list -->
- 사용자 데이터 기반 RAG 챗봇

<!-- block: 3d5fef49-d8d5-803a-adfe-e88c418f8e68; type: bulleted_list -->
- 계산 기능과 AI 대화를 연결하는 Function Calling

<!-- block: 3d5fef49-d8d5-80c7-8884-e900f6b3dada; type: bulleted_list -->
- 추천 이유를 제시하는 설명 가능한 AI

<!-- block: 3d5fef49-d8d5-80f1-9876-e73849690fd0; type: quote -->
어려운 금융관리를 숫자와 그래프가 아닌, 사용자의 행동에 따라 성장하는 캐릭터와 세계로 경험하게 한다.

<!-- block: 3d5fef49-d8d5-8094-b0b3-c789bd35b853; type: sub_header -->
### “예쁜 가계부”가 되지 않게 하는 장치

<!-- block: 3d5fef49-d8d5-808f-9fb6-c98a0c4ab862; type: text -->
가장 중요한 차별점은 보는 서비스가 아니라 행동하게 만드는 서비스라는 것입니다.

<!-- block: 3d5fef49-d8d5-8077-87a6-f90d0bac6b63; type: text -->
단순 기능:

<!-- block: 3d5fef49-d8d5-802a-a438-d4613258c55e; type: quote -->
이번 달 식비는 35만 원입니다.

<!-- block: 3d5fef49-d8d5-8006-a2b9-c7bae92cf35e; type: text -->
프로젝트의 기능:

<!-- block: 3d5fef49-d8d5-80b7-803f-d6946633e477; type: quote -->
식비가 목표보다 7만 원 높습니다. 앞으로 8일 동안 하루 1만 5천 원 이하로 사용하면 목표를 회복할 수 있습니다. ‘냉장고 탐험’ 퀘스트를 시작할까요?

<!-- block: 3d5fef49-d8d5-80df-919c-ec262e5fecd5; type: text -->
사용자가 퀘스트를 수락하면:

<!-- block: 3d5fef49-d8d5-802f-a16e-fc4b83576dcb; type: bulleted_list -->
- 진행 상황 자동 측정

<!-- block: 3d5fef49-d8d5-8025-9030-e3042ea4556b; type: bulleted_list -->
- 캐릭터 반응

<!-- block: 3d5fef49-d8d5-8080-9379-e63f27cf7958; type: bulleted_list -->
- 성공 가능성 갱신

<!-- block: 3d5fef49-d8d5-80aa-98df-d3ac84afef5b; type: bulleted_list -->
- 성공 시 성장 보상

<!-- block: 3d5fef49-d8d5-80a2-b492-e7245d6ed8c5; type: bulleted_list -->
- 다음 난이도 자동 조절

<!-- block: 3d5fef49-d8d5-80fe-a8ea-f2e3b6bdd8a1; type: text -->
까지 이어져야 합니다.

<!-- block: 3d5fef49-d8d5-8081-b7fe-f4f9b4c00cdb; type: sub_header -->
### 추천 MVP

<!-- block: 3d5fef49-d8d5-8069-a90a-db63fac1eb1d; type: text -->
처음에는 다음 범위가 적당합니다.

<!-- block: 3d5fef49-d8d5-8006-b295-f46978caba16; type: numbered_list -->
- 가상 계좌 또는 거래내역 CSV 연동

<!-- block: 3d5fef49-d8d5-8002-896c-ed830d05c523; type: numbered_list -->
- 거래내역 자동 분류

<!-- block: 3d5fef49-d8d5-8021-af8d-cfd646c51454; type: numbered_list -->
- 저축 목표 설정

<!-- block: 3d5fef49-d8d5-80ea-a725-e59ecff43330; type: numbered_list -->
- 소비 패턴에 따른 주간 퀘스트 생성

<!-- block: 3d5fef49-d8d5-80bc-9ec3-e522145acbbb; type: numbered_list -->
- 퀘스트 결과에 따른 캐릭터 성장

<!-- block: 3d5fef49-d8d5-80e7-b111-e4dadc02eb76; type: numbered_list -->
- 캐릭터와 금융 데이터 기반 대화

<!-- block: 3d5fef49-d8d5-80fd-9882-d98daefb107f; type: numbered_list -->
-  적금 상품 5~10개 비교 및 추천

<!-- block: 3d5fef49-d8d5-80ee-ab00-c2f4e72938d9; type: text -->
여유가 생기면 실제 계좌 연동, 캐릭터 꾸미기, 친구 기능, 금융 사기 탐지 등을 추가하면 됩니다.

<!-- block: 3d5fef49-d8d5-8033-beba-efd438e89340; type: text -->

<!-- block: 3d5fef49-d8d5-80f5-8e10-cb17505de976; type: quote -->
사용자의 실제 금융 행동으로 캐릭터와 세계를 성장시키는 AI 금융 습관 코칭 서비스

<!-- block: 65beff2d-104a-4f8d-960d-c31c6826b716; type: text -->
과거 금융사건을 배경으로, 당시 공개된 정보만 보고 투자 결정을 내리는 서비스입니다. 사용자는 자신의 투자 근거를 작성하고, 다른 사람의 판단을 읽은 뒤 믿을 만한 판단에 가상 포인트를 배분합니다.

<!-- block: edc61b90-5a9d-4617-a280-8e51d9c5dade; type: text -->
예를 들어 코로나 폭락이나 채권시장 불안 상황에서 “지금은 매수 기회다”와 “현금을 보유해야 한다”는 의견 중 누구의 논리를 믿을지 선택합니다.

<!-- block: 85d83702-9249-4634-86f1-ecb26ba80505; type: text -->
서비스 진행 방식

<!-- block: b1d66dc5-b109-47af-a62a-8b287e6883da; type: numbered_list -->
- 사건에 입장해 당시 뉴스·공시·가격을 확인합니다. 이후 정보는 숨깁니다.

<!-- block: 019f82a6-1d15-4a11-9494-261a3af2bc95; type: numbered_list -->
- 투자할 자산과 비중, 판단 이유, 예상 위험을 작성합니다.

<!-- block: 8cff931f-9993-4681-a0a7-3d17c67487e4; type: numbered_list -->
- 판단에 검증 가능한 전망과 확률을 붙입니다.예: “30일 후 지정된 채권지수가 현재보다 높을 확률은 70%”

<!-- block: 8f67537d-4078-4ebb-8fc4-5ae985230696; type: numbered_list -->
- 다른 이용자의 판단이 익명 카드로 공개됩니다.

<!-- block: e43bb8bd-5796-4388-b3d9-e0f62b08cdb5; type: numbered_list -->
- 설득력 있다고 생각하는 카드에 가상 포인트를 배분합니다.

<!-- block: 7d68eaf2-18c3-4607-9b14-92f8cf9ef895; type: numbered_list -->
- 시간이 진행되면 새로운 정보를 보고 판단을 유지하거나 수정합니다.

<!-- block: c8f58534-7d88-4d58-8648-a6629edff519; type: numbered_list -->
- 종료 후 투자 성과, 전망 정확도, 판단 근거에 대한 피드백을 확인합니다.

<!-- block: f08a6158-1bc6-4622-ba1b-84b3dc69c5a1; type: text -->
수정한 판단은 새 버전으로 남으며, 이전 판단과 포인트 배분 기록은 보존합니다.

<!-- block: 9d3fa8e5-7e33-4595-860c-b27e5993a2fb; type: text -->
차별점

<!-- block: 4e22ce0a-a0c3-4ee9-bf28-3c34a9a8e91f; type: text -->
일반 모의투자가 “어떤 종목을 살 것인가”에 집중한다면, 이 서비스에서는 “누구의 논리를 믿을 것인가”도 선택합니다.

<!-- block: cbf60e68-6ba9-4e55-b258-a73e462f07a6; type: text -->
이용자의 투자 의견 자체가 콘텐츠가 되고, 그 의견에 대한 신뢰를 포인트로 표현합니다. 단순 추천·좋아요보다 선택의 결과를 직접 경험할 수 있습니다.

평가의 공정성을 위해 결과 계산과 AI 피드백의 역할을 구분합니다.

<!-- block: 720633ce-9a37-4c24-adc3-4eb59268c4e6; type: table -->
<!-- block: 0317eae2-d086-42cc-a55c-713671967da1; type: table_row -->
| 구분 | 평가 내용 | 담당 |

<!-- block: 2779081f-740b-415e-a075-df8cb66583e5; type: table_row -->
| 투자 성과 | 실제 수익률과 손실 | 가격 데이터＋계산 코드 |

<!-- block: ab44b381-d25e-437b-86e7-db87cb44eaa9; type: table_row -->
| 전망 정확도 | 미리 작성한 확률과 실제 결과 비교 | 확률 채점 공식 |

<!-- block: 6e308f44-d2a1-4431-ab43-2bfc7ce171bd; type: table_row -->
| 근거 검토 | 공시·뉴스와 주장이 일치하는지 확인 | RAG＋LLM |

<!-- block: 1d0ead74-1ddd-424b-986e-b183612e00ef; type: table_row -->
| 판단 일관성 | 투자 비중·손실 한도·이후 행동의 관계 확인 | 계산 규칙＋기록 비교 |


<!-- block: 7226a260-14d5-42e6-83df-2afb803e8295; type: text -->
포인트는 AI의 주관적인 종합 점수로 정산하지 않습니다. 카드에 명시한 전망과 실제 결과를 사전 공개한 공식으로 비교합니다. 구체적인 지급 비율은 게임 설계 과정에서 조정할 예정입니다.

<!-- block: 674ff91e-f336-42f2-872d-3435b0d2fd1b; type: text -->
AI는 다음처럼 근거 있는 피드백을 제공합니다.

<!-- block: f0e4fba9-37b2-4b1d-87b4-6c6f0a131218; type: quote -->
“전체 자산의 80%를 투자하고 해당 자산의 15% 하락을 예상했다면, 전체 자산 손실은 12%입니다. 본인이 설정한 손실 한도 5%와 일치하지 않습니다.”

<!-- block: 101ba24a-7749-469d-a103-7763d959e577; type: text -->
공격적 투자 자체를 감점하지 않으며, 불확실한 해석은 ‘판단 유보’로 표시합니다. 전망이 맞았다고 그 논리까지 입증됐다고 보지는 않습니다.

## 실제 구현 흐름

<!-- block: 02861a4a-ace6-492d-ad58-fbe35bac6228; type: sub_header -->
### 1. 뉴스 입력

<!-- block: b506d271-7663-4258-848b-48b7d96e2e3a; type: text -->
사용자가 뉴스 URL 또는 본문을 입력합니다.

<!-- block: be0cac93-91c0-4db9-abb8-8344c1329cbb; type: code -->
```plain text
NVIDIA가 차세대 AI GPU 생산을 위해
TSMC의 첨단공정을 이용하고,
SK하이닉스의 HBM을 공급받는다.
```

<!-- block: 74853994-0df0-41a6-b6c4-7dbd0891f948; type: sub_header -->
### 2. LLM이 JSON으로 변환

<!-- block: b8a03bfa-7c94-430f-bdb0-6191fadff0f4; type: code -->
```plain text
{
  "companies": [
    "NVIDIA",
    "TSMC",
    "SK하이닉스"
  ],
  "products": [
    "AI GPU",
    "HBM"
  ],
  "event": {
    "type": "SUPPLY_CONTRACT",
    "subject": "NVIDIA",
    "direction": "positive"
  },
  "relations": [
    {
      "from": "TSMC",
      "to": "NVIDIA",
      "type": "PRODUCES_FOR"
    },
    {
      "from": "SK하이닉스",
      "to": "NVIDIA",
      "type": "SUPPLIES_TO"
    }
  ]
}
```

<!-- block: 547f419d-a96c-4c73-8c63-38d5e621d189; type: text -->
LLM에게 자유롭게 설명하도록 하는 게 아니라 정해진 JSON 형식으로 출력하게 하면 구현 난도가 많이 낮아집니다.

<!-- block: 21e0f6fc-f8d1-48b5-9fd9-abff04e9104f; type: sub_header -->

<!-- block: 0c19b531-2d3e-40d7-a744-3fd3f93f73d5; type: text -->

<!-- block: 7c50c450-90a1-4927-b789-27a234a105a1; type: code -->

```plain text
{
  "SK Hynix": "SK하이닉스",
  "에스케이하이닉스": "SK하이닉스",
  "000660": "SK하이닉스",
  "엔비디아": "NVIDIA",
  "Nvidia": "NVIDIA"
}
```

<!-- block: 4eb82cbb-75ee-48e5-ba53-15fe2f08034a; type: text -->
모든 기업을 처리할 수는 없지만 지원 기업 15개만 대상으로 하면 충분합니다.

<!-- block: 93dc5207-f3f9-47cd-b375-4b71eecbc12c; type: sub_header -->

<!-- block: 4acd8d6a-3fc8-48db-8c61-15bd653a753a; type: code -->

```plain text
SK하이닉스 —[PRODUCES]→ HBM
NVIDIA —[PRODUCED_BY]→ TSMC
```

NVIDIA로부터 두 단계 안에 연결된 기업·제품을 반환합니다.

## 현실적인 시스템 구조

<!-- block: 196eb5f5-a5b1-480a-a466-122c8f7eb15c; type: code -->
```plain text
React
  │
  ├── 그래프 화면
  ├── 뉴스 입력
  ├── 기업 상세
  └── AI 채팅
        │

        │
  ┌─────┴─────┐
  ↓           ↓
Neo4j      LLM API

  │
  ↓
```
