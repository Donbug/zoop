#### 평가금액

<!-- block: 62061e19-f651-4af8-83a6-80d546c9284a; type: text -->
        현재 보유한 주식을 지금 가격으로 계산한 총가치입니다.

<!-- block: 26b439c5-41c5-44ea-822d-7ee49b4c9013; type: code -->
```plain text
평가금액 = 보유수량 × 현재 주가
```

<!-- block: 904932c0-8ff2-4ab8-9451-f4ab450b96e1; type: text -->
        예를 들어 삼성전자 10주를 보유하고 있고 현재 주가가 75,000원이라면:

<!-- block: 096169d8-421f-42ab-8e82-2275a4604066; type: code -->
```plain text
10주 × 75,000원 = 750,000원
```

<!-- block: f72394a2-3b51-467c-a6a7-8eee25677a24; type: text -->
        평가금액은 현재 삼성전자 보유분의 가치가 75만 원이라는 뜻입니다.

<!-- block: 3e10407a-4983-4a1e-b706-e149cdb19cf9; type: sub_sub_header -->
#### 평가손익

<!-- block: 9877309e-b6ea-4006-816b-a4dd34cde31f; type: text -->
        주식을 산 금액과 현재 평가금액의 차이입니다. 아직 매도하지 않았기 때문에 확정된 손익이 아니라는 점이 중요합니다.

<!-- block: 7dd2920a-56d2-4023-a260-1e478cc5dc3a; type: code -->
```plain text
평가손익 = 평가금액 - 매입금액
매입금액 = 보유수량 × 평균 매입가
```
