| 신호 분류 | 애널리스트 의견, 산업 전반, 시장 이슈, 자회사 이슈처럼 원인을 묶음 | 기업, 산업, 공급망, 경쟁, 거시, 수급, 공시로 영향 요인을 분류 |

| 관계 설명 | 같은 산업군, 최근 20일 수익률 상관관계, 기업 설명을 제공 | 각 그래프 엣지에 관계 유형·기간·근거·신뢰도를 표시 |
| 반복 방문 | “새 시그널 6개 보기”처럼 새 변화만 강조 | 사용자의 보유·관심 종목에서 새로 생긴 이슈만 모아 알림·피드 제공 |
토스증권에서 가장 중요하게 가져올 것은 이 흐름입니다.
```
한 줄 시그널
→ 왜 그런 해석이 나왔는지
→ 어떤 종목과 이어지는지
→ 출처와 관계 근거
```
다만 토스의 “같은 산업”이나 “최근 20일 상관관계”는 원인 관계와 다를 수 있습니다. 여러분은 이를 그래프에서 절대 섞지 않아야 합니다.
```
LG에너지솔루션 ─ 경쟁 ─ 삼성SDI
LG에너지솔루션 ─ 지분·사업 관계 ─ LG화학
LG에너지솔루션 ┄ 최근 20일 주가 동조 ┄ 에코프로비엠
```
실선·점선·색상·관계 라벨을 다르게 써야 합니다.
Google Finance 사진에서는 다음을 벤치마킹하면 좋습니다.
| 구분 | Google Finance 화면 요소 | 우리 서비스 적용 |
| 좌측 패널 | 포트폴리오, 관심 목록, 업종 목록을 항상 노출 | 내 포트폴리오·관심 종목·관심 산업을 고정 탐색 영역으로 제공 |
| 중앙 시장 화면 | 지수 카드, 시장 요약, 주요 뉴스, 실시간 업데이트 | “오늘 내 포트폴리오 영향 이슈”와 시장·산업 요약을 중앙에 배치 |
| 우측 조사 패널 | 조사 결과와 후속 질문 입력창을 유지 | 선택한 종목·이슈·포트폴리오 맥락을 아는 챗봇을 상시 배치 |
| 출처 표시 | AI 조사 내용 옆에 여러 사이트 출처 표시 | 챗봇과 그래프의 모든 답변에 공시·뉴스·IR 출처 링크 제공 |
| 질문 유도 | “관심 목록에 대해 자세히 알아보기” 같은 시작 질문 | “내 종목의 공통 위험은?”, “이 이슈가 내 포트폴리오에 미치는 경로는?” 제안 |
| 넓은 작업 공간 | 목록·시장·조사를 동시에 보는 3단 레이아웃 | 데스크톱에서는 포트폴리오·그래프·챗봇을 동시에 표시 |
| 벤치마킹 포인트 | 항목 | 서비스 적용 |
| 복잡한 시장 상황을 먼저 짧고 쉽게 설명 | 한 줄 시그널 | “삼성전자 상승에 연결된 핵심 이슈 3개”를 첫 화면에 표시 |
| 뉴스·공시를 바탕으로 종목 변동 이유를 설명 | 종목별 이유 | 종목 → 이슈 → 영향 경로 그래프로 확장 |
| 같은 이슈로 함께 움직인 종목 제시 | 연관 기업 | 경쟁사·고객사·공급사·동조 종목을 관계 유형별로 분리 |
| 중요 정보부터 보여주고 상세 내용은 펼침 | 모바일 중심 UX | 그래프도 기본 1단계만 노출하고 필요할 때 확장 |
| AI 해석의 한계를 명확히 표시 | AI 고지 | “영향 가능성”, “근거 출처”, “신뢰도”를 함께 제공 |
| 보유·관심 종목을 기준으로 정보 구성 | 개인화 | 사용자가 관심 등록한 종목 중심으로 이슈 알림 제공 |
토스증권은 **“왜 움직였는지 쉽게 설명하는 방식”**을 벤치마킹합니다.
다만 여러분은 한 줄 설명에서 멈추지 않고, 그 원인이 다른 기업과 사용자 포트폴리오에 어떻게 전파되는지 보여주는 것이 차별점입니다.
