# 우리 서비스의 목표
우리 서비스의 목표는 ‘금융시장의 관계를 **지식그래프로** 축적하고, 사용자의 포트폴리오와 질문에 맞는 금융 지도를 제공하는 것’
1. 서비스 목표 — 포트폴리오에서 시작해 시장 전체로 확장되는 금융 지도
주식과 관계된 기업, 이슈등 기업의 사업과 주가 형성에 관련된 정보를 Graph DB에 축적하고, 사용자는 이 지도를 통해 기업들이 연결되는 이유와 시장 상황에 따른 변화를 이해하고, 근거를 확인
| 핵심 목표 | 서비스 구현 방향 |
| **시장 관계의 구조화** | 기업·산업·제품·사건·이슈와 관계의 근거를 축적 |
| **개인화된 금융 지도** | 포트폴리오·관심 종목을 중심으로 중요한 연결을 추출 |
| **시장 변화 반영** | 신규 사건과 시장 데이터에 따라 관계 상태·강도·중심 이슈 갱신 |
| **단계적 탐색** | 필요한 부분부터 보여주고 관련 기업·산업으로 확장 |
| **질문 기반 탐색** | 하나의 코파일럿에서 질문에 적합한 그래프·카드·수치·타임라인 제공 |
> 💡 
  주식 방향성(긍정/부정) 보여주는 부분이 아직 확실하지 않음
  이슈x기업 별 기대와 우려를 분석하여 실제 주가 흐름과 함께 보여준다.
  - 핵심은 뉴스가 긍정적인 것인지, 기업에 유리하다는 것인지, 주가가 상승한다는 것인지 구분해야함. 
  - 무엇의 긍정 부정인지 먼저 정의
    | 화면 표현 | 의미 | 분석값 |
    | 기대 요인 / 우려 요인 | 해당 기업의 매출·원가·생산·경쟁 환경에 대한 기대와 우려 | **뉴스 기반 사업 영향 해석** |
    | 수집 게시물의 반응 분포 | 수집한 게시물에서 나타나는 낙관·비관 의견 | **커뮤니티 반응** |
    | 최근 1일·5일 등락률 | 정해진 기간의 관측된 수익률 | **실제 가격 변화** |
  - 긍/부정 비율 계산
    - **대상:** 특정 이슈에 연결된 특정 기업.
    - **기간:** 최근 7일 등 명시한 기간.
    - **단위:** 전재·복제를 묶은 기사 그룹별 기업 영향 판정.
    - **분류:** 긍정·부정·혼재·중립·판단 불가.
    - **근거:** 각 판정의 원문 구간.
  - 그래프에서는 ‘방향’보다 ‘해석과 변화’ 보여주기
    이슈–기업 간선을 선택하면
    > 
      **AI 데이터센터 투자 ↔ 기업 A**
      **분석:**매출 기회에 관한 긍정 해석 우세
      **기대 요인:**관련 제품 수요 확대
      **우려 요인:**경쟁사의 공급 확대
      **미확인:**실제 납품 물량과 계약 규모
      **변화:**이전 기간 대비 긍정 해석 비중 증가
      **근거 보기:**관련 기사와 원문 구간

# 페르소나
### **투자는 하고 있지만, 보유 종목을 이해하는 데 많은 시간과 노력을 쓰기 어려운 사용자**
삼성전자처럼 익숙한 기업과 지인이 추천한 종목을 보유하고 있다. 주식 앱에서 수익률은 자주 확인하지만, 공시나 산업 보고서를 찾아 읽지는 않는다. 주가가 크게 움직이면 뉴스를 검색하지만 전문 용어가 어렵고, 여러 기사 중 무엇이 중요한지 판단하기 어렵다.
“전문가처럼 분석하고 싶다기보다, 적어도 내가 가진 주식에 무슨 일이 있는지는 알고 싶어요.”
| 항목 | 설정 |
| 투자 행동 | 익숙한 기업·추천받은 종목 위주로 투자 |
| 정보 확인 | 수익률 확인, 포털 뉴스, 짧은 영상 |
| 서비스 이용 계기 | 보유 종목 급등락, 눈에 띄는 뉴스, 추가 매수 고민 |
| 핵심 목표 | 내 종목의 상황과 확인할 사항을 짧은 시간에 이해 |
| 이용 장벽 | 전문 용어, 복잡한 화면, 무엇부터 봐야 할지 모르는 상태 |
| 원하는 경험 | 쉬운 설명 → 연결 이유 확인 → 필요할 때 근거 탐색 |
- 뉴스가 많은데 뭘봐야 하나요 → 중요 정보를 선별하기 어려움 → 내 보유 종목과 직접 연결된 변화부터 제시
- HBM 뉴스가 왜 삼성전자랑 관련돼요? → 제품·사업·이슈의 연결을 모름 → 연결 경로와 쉬운 한 문장 설명
- 이거 확정된 얘기예요? → 사실과 전망을 구분하기 어려움 → 발표·보도·전망·미확인 상태 구분
→ 그래프에 대한 상세한 설명 
→ 한줄 설명이 필요함
### **시장 흐름을 전반적으로 보고싶은 개인 투자자**
“AI 데이터 센터 투자가 늘어나서 이 이슈에 실제로 어떤 기업이 영향을 받는지, 단순 테마로 묶인 기업은 어디인지 구분하고 싶어요.”
| 설정 | 항목 |
| 특정 산업·이슈를 조사한 뒤 투자 후보 선정 | 투자 방식 |
| 뉴스·기업 자료를 여러 탭에 열고 직접 비교 | 현재 행동 |
| 실제 공급·고객 관계와 추정 관계가 섞여 있음 | 핵심 불편 |
| 관련 기업들을 동일한 기준으로 비교하고 근거 확인 | 원하는 결과 |
| 이슈 선택 → 관계 경로 확장 → 기업 비교 → 조사 결과 저장 | 서비스에서 할 행동 |
**제공 가치**
> 기업·이슈·근거를 그래프로 연결하고 관심 관계의 변화를 추적해, 사용자의 조사 시간을 줄이고 중요한 변화를 확인하도록 돕는다.
