# 문제정의
- 기존 챗봇은 사용자의 자유로운 자연어의 의도를 파악하고 ‘상품-조건-혜택-근거’까지 연결하지 못한다.
- 기존의 챗봇은 개인정보가 필요하지 않고 복잡한 계산이 필요하지 않은 질문에도 답을 제대로 하지 못하는 문제가 발생함

- 계속 상담사 연결로 대답을 돌리는 문제
# 문제 이유
- 데이터의 한계 : 범용 LLM가 금융 관련 답변을 하기에는 한국금융용어, 국내금융법규, 금융제도에 대한 전문데이터가 부족했음
- 과거 은행 내부 시스템의 **망분리 규제** 때문 : **과거 금융권의 망분리와 개인신용정보 활용 제한 때문에 외부 생성형 AI와 내부 금융 데이터를 연결하기 어려웠**
- 국내은행은 금융상품 정보는 존재하지만 PDF·약관·FAQ·DB 등에 파편화되어 있었음
- 금융상품 설명의 **정확성·보안·책임**을 통제해야하기 때문에 제대로 된 추천을 회피했음.
# 우리가 해결해야하는 문제
- 상품 추천의 정확성 AI agent의 신뢰도
- llm의 의도분류체계를 어떻게 분기할 것인지
  ```
LLM에게

> “이 사람 대출 한도 계산해.”

LLM
└─ 사용자의 말 이해

RAG
└─ 상품/약관/규정 검색

Graph
└─ 상품-조건-규정 관계 탐색

Rule Engine
└─ 가입 가능 여부 판단

Calculator
└─ 금리/상환액 계산

LLM
└─ 결과를 이해하기 쉽게 설명
```
- **개인화가 오히려 소비자 선택권을 줄이는 문제**
- 데이터 품질 및 보안 리스크
- 설명가능성(Explainability) 부족과 불완전성: AI가 대출 거절, 투자 추천 등의 결정을 내릴 때 그 이유를 투명하게 설명하지 못해 이용자가 결과를 신뢰하고 통제할 수 있도록
