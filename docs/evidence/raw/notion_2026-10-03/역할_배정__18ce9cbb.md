## 4. AI 담당 — 이슈 추출·관계 후보 생성
담당자: `__________`
### 담당 범위
- 기사·공시 전처리
- 기업·제품·산업 엔티티 추출
- 이슈 후보 구조화
- 임베딩 생성과 유사 후보 검색
- 같은 사건 군집화
- 이슈-기업 영향 관계 후보 생성
- 관련도·신뢰도·검수 상태 산정
- 품질 평가 데이터셋 작성
### P1 파이프라인
```plain text
뉴스 원문
→ 기업·제품·행위·시점 추출
→ 이슈 후보 JSON
→ 유사 후보 검색
→ 동일 사건 군집화
→ 상위 이슈 생성
→ 이슈-기업 관계 후보
→ VERIFIED / REVIEW_REQUIRED / REJECTED
```
### 완료 기준
- 기사 1건에서 구조화된 이슈 후보를 추출한다.
- 유사한 기사 여러 건을 하나의 이슈 후보로 묶는다.
- 이슈와 기업의 연결 근거 문서를 남긴다.
- 근거가 부족하면 `REVIEW_REQUIRED`로 보낸다.
- 모델이 생성한 후보를 바로 공개 GraphDB에 넣지 않는다.
### 맡지 않는 것
- 수집 스케줄러 운영
- GraphDB 적재 쿼리 작성
- 사용자용 챗봇 화면
- 투자 추천
