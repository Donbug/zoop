# 아이디어 구체화

**메인 화면에서 보여주는 콘텐츠가 아니라 개인화 기능을 작동시키는 분석 엔진**으로 내려가야 합니다.
즉, 서비스의 주인공을 “시장 이슈”가 아니라 **사용자의 실제 포트폴리오와 투자 결정**으로 바꾸는 겁니다.
> 기존 방향: 이슈와 종목의 관계를 보여주는 서비스
추천 방향: **내 포트폴리오의 보이지 않는 노출과 내 투자 판단의 변화를 추적하는 서비스**
이렇게 가면 단순 정보 전달 서비스라는 평가에서 확실히 벗어날 수 있습니다.
## 메인 기능 1: 포트폴리오 그림자 지도
계좌를 읽기 전용으로 연결하면, 사용자가 보유한 종목·비중·거래 내역을 기준으로 개인별 그래프를 만듭니다.
```plain text
내 포트폴리오
삼성전자 · SK하이닉스 · LG에너지솔루션

직접 보유
반도체 · 2차전지

그림자 노출
AI 데이터센터 투자
메모리 가격
중국 수요
미국 대중 규제
리튬 가격
원/달러 환율
```
이 기능의 핵심은 “어떤 종목을 사라”가 아닙니다.
> **나는 실제로 어떤 산업·국가·원자재·기업 이슈에 노출돼 있는가?**
를 보여주는 것입니다.
사용자는 종목을 여러 개 들고 있어도, 실질적으로는 반도체·중국 수요·환율이라는 같은 위험에 집중돼 있다는 사실을 알 수 있습니다. 이것이 Graph DB의 가장 설득력 있는 활용처예요.
## 메인 기능 2: 투자 결정 타임캡슐
사용자가 매수·매도하면, 그 순간의 시장 맥락을 자동 저장합니다.
```plain text
2026년 9월 10일
삼성전자 10주 매수

당시 시장 맥락
- HBM 수요 확대 기대
- 외국인 순매수 증가
- 반도체 업종 강세

현재 달라진 사항
- 중국 수요 둔화 우려 발생
- 경쟁사 공급 확대 전망
- 메모리 가격 전망 유지
```
이 기능은 사용자가 직접 투자 일지를 쓰지 않아도, 거래 당시의 이슈·주가·산업 흐름·관계 그래프를 남겨주는 기능입니다.
나중에 사용자는 단순히 수익률만 보는 대신:
- 내가 이 종목을 산 당시 전제는 무엇이었나?
- 그 전제는 지금도 유효한가?
- 새로 등장한 반대 근거는 무엇인가?
- 같은 이슈가 내 다른 종목에도 영향을 줬는가?
를 확인할 수 있습니다.
이건 토스의 “왜 오늘 움직였나?”보다 더 개인적이고, Google Finance의 일반 금융 챗봇보다도 계좌 데이터와 관계 그래프를 활용한다는 점에서 차별화됩니다.
## 기존 기능의 위치
| 기존 기능 | 새로운 역할 |
| 이슈별 그래프 | 그림자 노출의 근거를 설명하는 상세 화면 |
| 개별 종목 그래프 | 포트폴리오 내 특정 종목을 깊게 분석하는 화면 |
| 뉴스 피드 | 내 보유 종목·그림자 노출과 관련된 정보만 선별 |
| 기업 관계도 | 집중 위험과 이슈 전파를 보여주는 분석 엔진 |
| 챗봇 | 내 거래와 포트폴리오 맥락을 질문하는 인터페이스 |
그래프는 여전히 서비스의 기술적 핵심이지만, 사용자는 “그래프를 보러” 오는 것이 아니라 **내 자산을 이해하려고** 들어오게 됩니다.
## 추천 메인 화면
```plain text
내 포트폴리오 그림자 지도

오늘 새로 커진 노출
[AI 데이터센터 투자]  반도체 보유 비중 34%에 연결
[중국 수요 둔화]      2차전지 보유 비중 22%에 연결

내 포트폴리오 공통 위험
AI 메모리 수요        38%
중국 수요·규제        29%
원/달러 환율          21%

최근 거래 이후 달라진 전제
삼성전자 매수 이후
새 반대 이슈 2개 · 유지된 핵심 근거 3개

[내 포트폴리오에 질문하기]
```
## MVP 우선순위
1. 읽기 전용 계좌 연결
1. 보유 종목·비중 기반 포트폴리오 그림자 지도
1. 매수·매도 시점의 자동 시장 맥락 저장
1. “내 포트폴리오에 질문하기” 챗봇
1. 개별 종목·이슈 그래프는 상세 탐색 기능으로 제공
계좌 연동을 한다면 반드시 읽기 전용으로 시작하고, 보유 종목·거래 내역은 민감한 금융정보이므로 명확한 동의, 연결 해제, 데이터 삭제, 최소 수집 원칙을 제품 설계에 포함해야 합니다.
이 방향은 서비스성을 훨씬 강하게 만듭니다. 단순히 시장을 설명하는 서비스가 아니라, **사용자의 실제 투자 판단과 위험 노출을 시간에 따라 이해시키는 금융 인텔리전스 서비스**가 됩니다.
### 의문점
1. 투자결정 타임캡슐에서 사용자가 주식을 매수할때 상황을 읽고 하는게 아니라 자신이 이미 사던거라 그냥 꾸준히하는 경우에는 어떻게 처리해야할지 모르겠어요
  ㄴ 투자자의 원래 판단 근거와 AI가 관찰한 시장 맥락을 어떻게 분리할 것인지. 사용자가 꾸준히 적립식으로 사는 주식 같은거는 미리 설정에서 적립식 자동 투자 이런식으로 설정할 수 있게 해두면 좋을거같아요.
1. AI 자연어 질의로 검색결과를 관계도 그래프를 보여주는 기능과 챗봇을 구분하는 방향이 맞을지 좀 더 생각해보고싶음→ 이거를 하나의 챗봇에서 질의를 구분해서 답변을 구분 가능한지 검증하는 것이 필요.
1. 아직 개인화의 기능이 약한 부분이 존재. 단지 개인의 보유 포폴에 대한 위험을 알려주고, 매매 할 때 매매에 대한 분석이 전부인 듯한데, 킥이 부족함
1. 기능들이 “포트폴리오 분석” 이라는 하나의 개념을 공유하지만 그 안에서 유기적으로 연결되지 않고 따로 노는 느낌이 강함. 통합할 수 있는 서비스가 나뉘어져 있으며 서비스 간의 연결도 없는 수준임.
  1. 예를 들어, 현재 나뉘어있는 (문서상 제목) “포트폴리오 그림자 지도”와 “투자 결정 타임캡슐”이 동일한 수준의 메인 기능으로써 같은 비중을 가지는 데 비해 둘 사이 가지는 연계성은 약함. 지도에서 내 결정을 바로 볼 수 있게 한다거나, 타임캡슐을 지도에 통합하여 과거 기록을 볼 수 있게 하는 등 보다 연계할 수 있는 점이 많은데 둘 중 하나를 메인 기능으로 내세우기보다는 “둘 모두 메인 기능” 이라는 부분에 사로잡혀 어필만 하고** 실질적 기능의 연계와 하나의 서비스로 묶는 이점이 사라지는 점이 상당히 아쉬움.**
1. 사용자의 실제 투자 판단과 위험 노출을 **시간**에 따라 이해시킨다는 건 타입캡슐 기능에 따른 설명인가요?

  ## 1. 투자 근거 입력은 ‘선택사항’으로
  AI가 매수 시점의 뉴스·공시·산업 상황을 분석해 후보를 먼저 제시합니다.
  ```plain text
  삼성전자 매수 당시 주요 시장 맥락
  
  ☑ HBM 수요 증가 기대
  ☑ 메모리 가격 상승 전망
  □ 외국인 순매수 증가
  □ 원/달러 환율 상승
  ＋ 직접 입력
  ```
  사용자는 맞는 항목만 고르면 됩니다. 아무것도 선택하지 않아도 포트폴리오 분석은 작동합니다.
  단, 명칭을 구분해야 합니다.
  - 사용자가 확인하지 않음 → `매수 당시 시장 맥락`
  - 사용자가 선택하거나 입력함 → `나의 투자 근거`
  AI가 자동으로 수집한 내용을 사용자의 실제 생각이라고 단정하면 안 됩니다.
  ## 2. 주가에 영향을 준 원인을 ‘확정’하지 않기
  주가에는 동시에 수많은 요소가 영향을 줍니다.
  - 기업 실적과 공시
  - 산업 수요와 공급
  - 경쟁사 움직임
  - 금리·환율·원자재
  - 정부 규제와 정책
  - 외국인·기관 수급
  - 시장 전체의 상승·하락
  - 투자심리와 예상치
  - 이미 주가에 반영된 정보
  그래서 AI가 “이 뉴스 때문에 5% 상승했다”고 말하면 위험합니다. 실제 인과관계를 증명하기 어렵기 때문입니다.
  대신 이렇게 표현해야 합니다.
  ```plain text
  삼성전자 오늘 4.2% 상승
  
  가능성이 높은 관련 요인
  
  1. 메모리 가격 전망 상향        관련도 높음
     - 당일 관련 보도 5건
     - SK하이닉스도 3.1% 상승
     - 반도체 업종지수 2.4% 상승
  
  2. 외국인 순매수 증가           관련도 중간
     - 최근 5일 중 최대 순매수
  
  3. 원/달러 환율 변화            관련도 낮음
     - 수출기업에는 긍정적이나 당일 변동은 작음
  
  확인되지 않은 요인
  - 개별 투자자의 매매
  - 시장에 공개되지 않은 정보
  ```
  정답을 말하는 서비스가 아니라, **근거가 있는 설명 후보를 순위화하는 서비스**가 되는 겁니다.

  ## 관계도 검색과 챗봇: 하나의 챗봇으로 통합하는 게 맞음
  별도의 “AI 자연어 검색”과 “챗봇”을 만들 필요는 없습니다. 사용자는 둘의 차이를 잘 느끼지 못할 가능성이 큽니다.
  대신 하나의 **포트폴리오 그래프 코파일럿**을 만들고, 질문 의도에 따라 결과 형식을 바꾸면 됩니다.
  | 사용자 질문 | 내부 처리 | 응답 형태 |
  | “삼성전자와 SK하이닉스 관계 보여줘” | 관계 탐색 | 관계 그래프 |
  | “오늘 내 포트폴리오에 중요한 이슈는?” | 보유 종목·이슈 분석 | 우선순위 이슈 카드 |
  | “유가 상승이 내 포트폴리오에 미치는 영향은?” | 시나리오 경로 탐색 | 긍정·부정 영향 그래프 |
  | “내 반도체 노출이 얼마나 돼?” | 포트폴리오 집계 | 노출도 그래프 |
  | “삼성전자 매수 당시 상황은?” | 투자 챕터·시장 맥락 조회 | 타임라인 |
  즉, 챗봇은 입력 방식이고 그래프는 출력 방식입니다.
  ```plain text
  사용자 질문
  → 질문 의도 분류
  → Graph DB / 뉴스 / 공시 / 포트폴리오 데이터 조회
  → 텍스트 · 관계도 · 타임라인 · 비교표 중 적절한 결과 출력
  ```
