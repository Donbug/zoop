## 켜는 순서

1. 운영자 챗봇 grant 파일에 원천 `zoop-docs`의 `model-send` grant가 있는지 확인합니다. 정책 문서도 같은 원천을 씁니다.
2. 대상 환경에서만 `ZOOP_CHAT_APPROVED_DOCS_ENABLED=true`로 배포합니다. 문서가 없거나 절이 20개를 넘거나 한 절이 2,000자를 넘으면 기동을 거절합니다.

## 개정

승인본은 적용 뒤 수정·삭제하지 않습니다. 각 절은 현재 `web/` 화면 동작과 맞아야 하고, 와이어프레임이나 프로토타입만 근거로 쓴 문장은 남기지 않습니다.

1. 새 버전 파일을 `docs/help/approved/<문서>-<버전>.md`로 추가하고 승인 근거를 받습니다.
2. 새 Flyway migration으로 기존 버전에 `retired_at`을 기록하고 새 버전을 넣습니다. 시행 기간은 겹칠 수 없습니다.

`##` 절 하나가 인용 하나입니다. 한 절은 2,000자, 한 문서는 20절을 넘지 않습니다. 두 문서는 20절 상한에 차 있으므로 절을 더하려면 합치거나 문서를 나눠야 합니다.
