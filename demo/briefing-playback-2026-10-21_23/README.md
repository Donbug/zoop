# 완성 브리핑 시연 (D-BRF-01/02)

2026-10-21 퇴근 → 10-22 출근·퇴근 → 10-23 출근, 완성된 4회차의 화면 조회 결과입니다.
생성 입력을 다시 돌리는 작업이 아닙니다. 새 모델 호출·시세 조회·비용은 없습니다.

PR 브랜치를 checkout/pull한 뒤 저장소 루트에서 실행합니다.
Python 3.10+, Node.js 22.12+와 pnpm 10이 필요합니다.

```sh
# 처음 한 번만 웹 의존성 설치. 이미 설치했으면 생략합니다.
HUSKY=0 pnpm --dir web install --frozen-lockfile
python3 scripts/briefing_playback.py
```

출력된 주소를 엽니다: <http://127.0.0.1:13196/briefing?date=2026-10-23&edition=morning&reading=compact>.
화면에서 날짜와 출근·퇴근을 바꾸면 저장된 나머지 회차가 연결됩니다.
`reading=full`로 현재 이슈별 전문도 볼 수 있습니다. 다른 시연 서버는 종료하지 않습니다.
포트가 사용 중이면 `--web-port 13197 --api-port 18197`처럼 두 포트를 지정합니다.
종료는 Ctrl-C입니다. Docker, Java, 실제 DB, 모델 키, 개인 `.env`는 필요 없습니다.

## 포함한 자료

- `*.json`: 완성된 브리핑 응답과 해당 핵심 이슈의 상세 응답만 포함합니다.
  문안, 선정 이슈, 기업 판단, 저장 시세, 이전 회차 비교, 짧은 근거 인용과 링크를 유지합니다.
- `manifest.json`: 회차·결과 버전·이슈 수·파일 크기·SHA-256입니다.
- 생성 후보·프롬프트·입력/호출 해시·모델 호출 영수증·기사 전체 본문·주변 본문·DB 덤프·사용자 평가·세션은 포함하지 않습니다.
  과거 생성 버전 전체 아카이브와 미병합 #413 작업용 필드도 제외합니다. 이전 회차의 실제 판단은 현재 완성본이 고정한 비교 문안과 다른 회차 조회에서 확인합니다.
- 현재 이슈별 최종 문안/판단/조건/비교, 저장된 지표와 가격 관측, 짧은 인용/출처 링크를 유지합니다.
  모델명·판정 방식·생성 시각·결과 버전은 화면 검증 상태와 평가 대상을 연결하는 완성 결과 메타데이터입니다.
  `bodySha256`은 짧은 인용의 공개 원문 식별자이고 입력 본문은 없습니다. 파일 무결성은 manifest의 파일 SHA-256으로 확인합니다.
- `manifest.responseFields`는 허용된 조회 필드 목록입니다. 현재 이슈 판단과 시장 지표는 원본 완성본과 동일함을 확인했습니다.
  이번에 새 모델 생성/검증을 수행한 결과가 아닙니다.

역사 자료를 사후 재분석한 시뮬레이션이라는 기존 고지를 유지합니다.
10/23 출근 이전에 없던 실시간 관측이나 관계 그래프를 만들어 붙이지 않습니다.
회원 로그인, 내 종목, 관리자 집계, 지도·S3 분석은 이 브리핑 전용 서버의 제공 범위가 아닙니다.
미제공 요청은 404 또는 명시적 unavailable로 응답합니다.
기존 `api/demo/briefing-2026-10-21_22`와 생성용 archive는 변경하지 않습니다.

## 평가 저장 연결

스크린샷의 문구는 회원용 `/api/v1/feedback` 저장 실패 안내입니다.
회원 API와 인증이 없는 조회 시연 서버에 일반 웹 설정을 붙이면 평가가 저장되지 않습니다.
이 실행 명령은 프록시 주소, API 기본 주소, `VITE_BRIEFING_PREVIEW_FEEDBACK=true`를 함께 설정해
기존 시연 평가 UI와 `/api/local/briefing-feedback` 저장 API를 같은 origin으로 연결합니다.
기존 회원 평가 구현/PR과 별도로 동작하며 성공 메시지만 흉내 내지 않습니다.

평가는 `.local/briefing-playback/feedback.sqlite3`에 실제 저장됩니다(Git 제외).
브라우저의 HttpOnly 식별 쿠키와 CSRF로 회차·이슈·결과 버전에 묶입니다.
도움/비도움, 사유(선택, 200자), 취소와 새로고침 후 재조회가 가능합니다.
같은 서버/브라우저로 다시 열면 유지됩니다. 팀원의 평가는 각자의 PC에 저장되며 공유되지 않습니다.
이전 개인 평가 DB는 복사하거나 운영 집계로 보내지 않습니다.
별도 시연을 분리하려면 `--state-dir /tmp/zoop-video-demo`를 지정합니다.

```sh
python3 scripts/briefing_playback.py --check
python3 -m unittest discover -s scripts/tests -p 'test_briefing_playback.py'
```
