# #93 · 기업 정보 탭 인계

2026-10-15 · WBS 6.7.10 · FS038 / FS044 · 루트 `web/`.

## 변경 범위

최신 main `6f681fd`에서 기존 로컬 #93 작업만 분리했다. 이미 병합된 #92 문서 기능과 #94·95의 그래프·차트 기능을 다시 포함하지 않는다. 기존 로컬 폴더는 보존했다.

- `CompanyWorkspace`가 조회한 `GET /api/v1/companies/{id}` 리소스를 `CompanyInfoTab`에 전달한다. 탭 전환으로 API 요청을 추가하지 않는다.
- 정식 법인명, 시장, 업종, 대표자, 설립일, 홈페이지를 표시한다. null·공백은 미제공으로 남기며 표시명을 정식 법인명으로 추정하지 않는다.
- 로딩, 빈 상태, 권한 없음, 404, 버전 미제공, 일반 실패 및 같은 조회 조건 재시도를 구분한다. 부분 실패는 제공된 필드와 실패 안내를 함께 표시한다.
- 다른 기업 ID 응답은 API consumer에서 거부한다. 기업·조회 시점 전환 중 이전 정보는 숨기며 늦게 도착한 이전 응답은 폐기한다.
- 홈페이지는 인증정보가 없는 절대 HTTP(S) 주소만 링크한다. 외부 홈페이지 내용은 조회하지 않는다.
- 관계·요약 자료의 asOf와 기업 기준정보의 별도 갱신 시각을 구분한다.
- Tailwind 두 열 정의 목록과 모바일 한 열 레이아웃, 기존 zoop 토큰 및 `panelStyles.button`을 사용한다. CSS 파일·인라인 스타일·패키지를 추가하지 않는다.

## 화면 추적

WBS는 D-COM-03이지만 와이어프레임 manifest는 기업 정보 탭을 D-COM-01, node 663:13515로 분류한다. 구현의 `data-screen-id`와 `data-wireframe-screen-id`로 두 기준을 추적하며 정본 manifest를 바꾸지 않는다. `docs/wireframe/boards/04-company-detail.jpg`와 해당 개별 화면을 확인했다.
