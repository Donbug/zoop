# D-COM-01 금액·기준 시각 표시 검증 (F6·F7)

기준 main: `86c8f530`. 2026-10-29 로컬 Chrome, 1440×900 / 390×844.
`measurements.json`은 렌더링한 금액과 `<time>`의 표시 문자열·원래 dateTime을 기록합니다.

- 본문 가격과 전일 대비 금액에 기존 `formatMoney`를 적용했습니다. KRW는 `원`, USD는 `$`로 표시합니다. 환산·새 수치·색 변경은 없습니다.
- 공개 자료 기준·공급자 관측·모의 수량/평가 기준·차트 표·재무 기준 시각은 기존 `formatKst`로 표시하고 원래 ISO 값은 `time.dateTime`에 보존합니다.
- null 가격·전일 대비는 `미제공`, null 공급자 관측은 `시각 미제공`, 실제 0은 `0원`입니다.
- 사건의 timePrecision 관련 시각은 이번 범위에서 제외했습니다. asOf·graphAsOf·API 쿼리·차트 선택 동작은 유지했습니다.
- 로컬 API의 공개 그래프와 가상 계좌는 합성 fixture입니다. 시세는 로컬 API 공급자 응답이며 운영 데이터나 투자 권유가 아닙니다. 테스트는 fakeServer를 사용합니다.
