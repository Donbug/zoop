# F1·F2·F5 화면 검증

화면 검사 보고서(2026-10-29)의 작업 1. D-AUT-02, D-WAT-01, D-GRP-01, FS001 404 및 공통 하단 메뉴.

로컬 API + 합성 그래프 fixture 및 테스트 계정으로 촬영했다. 보유는 프로젝트용 모의 계좌이고 시세는 공급자 관측값이다. 비밀값·세션 쿠키는 포함하지 않는다. 수정 전 이미지는 감사 보고서의 d13869e7 계열 증거이다. 시각·시세가 다른 두 이미지를 가격 정확성 비교로 해석하지 않는다.

`authNote`는 가입 외에 로그인 비회원 안내 팝업에서도 사용한다. [라이트 로그인](login-light-390.png)·[다크 로그인](login-dark-390.png)을 확인했다. 로그인 하단 안내에는 기존 `text-zoop-muted!`가 있어 변하지 않는다. 비회원 안내 팝업의 흰 배경에는 muted 대비가 약 6.10:1, 다크 paper 배경에는 약 12.09:1이다. 문구·버튼·로그인 동작은 유지한다.

실제 DOM 크기·색과 화면 전체 가로 넘침은 [measurements.json](measurements.json)에 기록했다. 모든 촬영 폭에서 문서 가로 넘침은 0px이다. 지도 기본 서체 레시피가 범례에 `min-h-7!`를 적용하므로, 지도 루트의 모바일 한정 Tailwind 선택자로 40px 최소 높이를 보장했다. 패널 닫기·액션, 데스크톱 크기, 노드/연결선/튜토리얼 동작은 변경하지 않는다.

회귀 검증은 클래스 스냅샷 대신 활성 색 토큰과 모바일 한정 최소 크기 클래스, 실제 도움말 조작을 확인한다. 수정 전 코드에서 관련 테스트 실패를 확인했다. 기존 튜토리얼 완료 테스트의 병행 실행 시간 초과는 단독 재실행으로 구분했다.
