# D-GRP-01 / D-GRP-07b 검증 이미지

실제 앱의 index/router/MapPage를 사용한 합성 그래프(기업 24·사건 43)와 비회원 세션입니다. 별도 GraphCanvas 화면이나 운영 계정·데이터를 사용하지 않았습니다.

## 캡처 범위와 제한

- 통합 기반 `591086fb`에 이번 미니맵·카메라 복귀·포커스 상자 수정을 적용한 중간 검증 화면입니다.
- 이후 #558·#559 최신 head 및 #563/#565 (`3595455f`)·#564 (`53137c4f`)를 추가 통합했습니다. 최신 기반에서는 SOURCE/AS OF 등 보조 표기가 이 이미지와 다를 수 있습니다.
- 최신 기반의 브라우저 재확인은 컴퓨터 사용 도구가 현재 URL을 확인하지 못해 중단됐습니다. 이 이미지를 최신 통합 head의 화면 검증으로 간주하지 않습니다. 최신 기반 자동 검사 결과는 PR 본문에 별도로 기록합니다.
- 사용자 결정에 따라 모바일 상세 모달(50%/90%)의 동작을 유지하며, 모달 뒤 미니맵 가림을 허용합니다.
