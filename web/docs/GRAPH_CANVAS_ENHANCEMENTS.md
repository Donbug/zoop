## 구현 시 주의할 점

1. G6 Label은 그룹과 자식 text/background의 visibility를 함께 바꿔야 한다. 그룹만 숨기면 글자가 남는다. 다시 보일 때는 먼저 복원하고 경계를 측정한다.
2. G6 상태 재그리기 후 updateNodeData의 labelFontSize와 실제 Label 기본값이 다를 수 있다. 공개 Label.update로 동일한 읽기 스타일을 적용한 후 충돌을 계산한다.
3. appearance 객체의 참조 변화만으로 renderer를 파괴하지 않는다. 테마 값으로 memoize하고 선택 변경은 기존 인스턴스에 반영한다.
4. G6 mock 검사는 실제 캔버스·터치 검증과 구분한다. 밀집 fixture에 실제 브라우저를 함께 사용한다.
5. 좌표와 카메라는 분리한다. 카메라는 화면 크기와 함께 검증하고, 노드 좌표는 회원·스냅샷·배치를 섞지 않는다.
