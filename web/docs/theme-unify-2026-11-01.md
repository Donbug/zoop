# 기업 상세·공통 테마 통합 (2026-11-01)

화면: D-COM-01·01b·02·05·06. 기준: D-AUT-01 로그인, D-GRP-T~T5 튜토리얼,
D-GRP-01/03 개선 지도. 최신 main `78224b71`에서 시작했다.

## 범위

기업 상세의 세 열·섹션·탭·데이터·문구·차트 선택 동작을 유지하고 면·테두리·모서리·간격만 맞춘다.
AppLayout의 기업 경로에서만 새 페이지/헤더 표면을 적용한다. 종목 목록에는 적용하지 않는다.
공통 다크 글자는 사용자가 선택한 브리핑 팔레트로 올리고, 브리핑의 중복 글자색 재정의만 제거한다.

## 공용 토큰

기존 `zoop-paper/wash/soft`, `panel-soft/line`의 바탕 값은 유지한다.
새 표면이 필요한 화면에서만 다음 Tailwind 토큰을 사용한다. 값은 개선 지도의 기존 값이다.

| 토큰            | 라이트    | 다크      | 용도                   |
| --------------- | --------- | --------- | ---------------------- |
| `zoop-page`     | `#f7f7f5` | `#171717` | 페이지 바탕            |
| `zoop-surface`  | `#ffffff` | `#262626` | 헤더·외부 패널·입력    |
| `zoop-card`     | `#f5f5f4` | `#2b2b2d` | 패널 안 섹션·차트 영역 |
| `zoop-control`  | `#efefed` | `#303032` | 보조 조작·문서 인용    |
| `zoop-border`   | `#d9d9d6` | `#414144` | 패널·입력 테두리       |
| `zoop-selected` | `#ededeb` | `#363638` | 선택한 기업 행         |
| `zoop-on-ink`   | `#ffffff` | `#171717` | 기본 버튼의 반전 글자  |

패널은 `rounded-xl border shadow-sm`, 섹션은 `rounded-lg bg-zoop-card`,
보조 조작·입력은 `rounded-md`를 사용한다. 글자 크기 6단계와 세 글꼴은 유지한다.

## 다크 글자와 대비

| 역할                    | 이전      | 변경      | `#171717` 대비 | `#262626` 대비 |
| ----------------------- | --------- | --------- | -------------- | -------------- |
| ink / panel-ink         | `#ededed` | `#fafafa` | 17.18:1        | 14.50:1        |
| muted / panel-secondary | `#a0a0a0` | `#d4d4d4` | 12.09:1        | 10.21:1        |
| faint / panel-muted     | `#8f8f8f` | `#a3a3a3` | 7.11:1         | 6.00:1         |

가장 낮은 조합인 faint/selected도 4.78:1이다. 라이트 글자는 계속 `#212121`이다.
루트·로그인·개선 지도·G6 `appearanceColors()`를 같은 팔레트로 맞춘다.
지도 연결선·탭 밑줄·시세 및 판정 의미색은 별도 변경하지 않는다.

## 남은 일

- 열린 #461과 겹치는 `web/docs/ui-style-guide.md`의 Dark theme 절은 수정하지 않았다.
  병합 후 이 문서의 팔레트/토큰을 해당 절로 옮겨야 한다.
- #461·#459·#425와 겹치는 브리핑 컴포넌트/페이지는 수정하지 않았다.
  브리핑 카드/버튼 모서리·구분선 통합은 후속이다.
- `next-task-dark-label-2026-11-01.md`의 선택하지 않은 기업 이름까지 ink로 바꾸는 작업은 후속이다.

## 검증 자료

합성 HTTP 자료와 개발용 mock 지도를 사용한다. 실제 회원·운영 데이터·실제 AI 호출은 사용하지 않는다.
브리핑 캡처는 발행된 합성 빈 회차이며, 기업 상세는 시세·차트·사건·빈 상태·지표 실패 상태를 포함한다.
회원 보유 상태 등은 기존 기업 상세 테스트로 확인한다.
