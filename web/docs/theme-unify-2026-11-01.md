# 기업 상세·공통 테마 통합 (2026-11-01)

화면: D-COM-01·01b·02·05·06, D-BRF-01·02. 기준: D-AUT-01 로그인, D-GRP-T~T5 튜토리얼,
D-GRP-01/03 개선 지도. 최신 main `78224b71`에서 시작했다.

## 범위

기업 상세의 세 열·섹션·탭·데이터·문구·차트 선택 동작을 유지하고 면·테두리·모서리·간격만 맞춘다.
AppLayout의 기업 경로에서만 새 페이지/헤더 표면을 적용한다. 종목 목록에는 적용하지 않는다.
공통 다크 글자는 사용자가 선택한 브리핑 팔레트로 올린다. 브리핑의 중복 글자색 선언을 제거하고, 공통/개인화 카드·섹션·조작을 같은 표면 토큰으로 맞춘다.

## 공용 토큰

기존 `zoop-paper/wash/soft`, `panel-soft/line`의 바탕 값은 유지한다.
새 표면이 필요한 화면에서만 다음 Tailwind 토큰을 사용한다. 값은 개선 지도의 기존 값이다.

| 토큰            | 라이트    | 다크      | 용도                   |
| --------------- | --------- | --------- | ---------------------- |
| `zoop-page`     | `#f7f7f5` | `#171717` | 페이지 바탕            |
| `zoop-surface`  | `#ffffff` | `#262626` | 헤더·외부 패널·입력    |
| `zoop-card`     | `#f5f5f4` | `#2b2b2d` | 패널 안 섹션·차트 영역 |
| `zoop-control`  | `#efefed` | `#303032` | 보조 조작·문서 인용    |
| `zoop-border`   | `#d9d9d6` | `#414144` | 패널·입력 테두리       |
| `zoop-selected` | `#ededeb` | `#363638` | 선택한 기업 행         |
| `zoop-on-ink`   | `#ffffff` | `#171717` | 기본 버튼의 반전 글자  |

패널은 `rounded-xl border shadow-sm`, 섹션은 `rounded-lg bg-zoop-card`,
보조 조작·입력은 `rounded-md`를 사용한다. 글자 크기 6단계와 세 글꼴은 유지한다.

2026-11-01 후속 요청으로 main `168803bf`를 pull했다. 사용자가 미병합 PR도
병합됐다고 가정하도록 승인하여, 다음 웹 변경을 임시 기준에서 결합했다.

임시 기준 `feat/web-theme-briefing-web-base`는 웹 스냅샷만 담는다. API·DB는
main 그대로다. 부모 PR 사이의 API/계약 충돌을 해결한 백엔드 통합본이 아니며,
실제 API 병합/검증과 혼동하지 않는다. 필요한 응답 계약은 부모 PR의 계약을
읽어 확인했고, 화면 검증은 합성 HTTP 응답과 기존 가짜 서버 테스트로 수행한다.

브리핑의 공통 카드·섹션·빈 상태·회차/읽기 조작·기업 시세/전망·정정·개인화
설정/생성의 표면·모서리·테두리를 같은 토큰으로 맞춘다. 개인화는 이미 자체
패널이 있으므로 바깥 article의 중복 테두리만 생략한다. 기능·문구·순서는 유지한다.
스타일 가이드의 새 토큰/다크 값도 이 요청에서 반영한다.

PR은 임시 웹 기준을 대상으로 한 Draft이며 부모 PR과 실제 main 통합 뒤
main을 기준으로 다시 검증/재지정해야 한다. 다른 팀의 기능 변경과 테마 변경을
같은 diff에 섞지 않는다. 다크 지도 기업 이름표의 ink 통일은 별도 후속이다.

## 검증 자료

합성 HTTP 자료와 개발용 mock 지도를 사용한다. 실제 회원·운영 데이터·실제 AI 호출은 사용하지 않는다.
첫 캡처는 합성 빈 회차이고 후속 `briefing/` 캡처는 합성 이슈가 있는 공통 간단히/전체 보기 및 개인화 설정 상태다. 기업 상세는 시세·차트·사건·빈 상태·지표 실패 상태를 포함한다.
회원 보유 상태 등은 기존 기업 상세 테스트로 확인한다.
