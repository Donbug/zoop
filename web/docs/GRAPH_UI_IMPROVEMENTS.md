## 바뀐 동작

상단의 단순 개수 표기와 왼쪽 표시 필터를 하나의 상단 필터로 통합한다. 직접 관련·구조적 관련·후속 사건 버튼은 실제 간선 visibility를 바꾸고, 개수는 전체 조회 스냅샷 기준으로 유지한다. 꺼짐 상태는 흐리게 표시하고 `aria-pressed`로 전달한다. 각 관계 설명은 기존 툴팁을 유지한다.

2026-11-04 결정:

- 기업·사건은 끌 수 없는 개수 표시다. 전에 저장한 기업·사건 숨김 값은 복원하지 않는다.
- 사건 공유 선과 버튼을 없앴다. 공유 사건은 접지 않고 늘 보이므로 기업–사건–기업 연결과 같은 내용이었다. API의 `SHARES_ISSUE` 응답은 그대로 두고 지도에서만 그리지 않는다. 기업 상세의 관련 기업 목록은 이 응답으로 계속 만들고, 행을 누르면 두 기업과 공유 사건, 그 사이 선만 밝게 남긴다. 다시 누르거나 다른 노드를 고르면 풀린다. 사건 공유 관계 상세 패널은 지도에서 열 수 없다.
- 사건 노드는 마름모 대신 원으로 그린다(지름 64). 32·64·80을 비교한 뒤 64로 정했다. 일반 기업(83–119)보다 작고 가장 큰 기업(188)의 약 1/3이다. 기업 노드는 1–3단계를 약 35%, 4–5단계를 약 27% 키웠다(61/74/88/115/149 → 83/100/119/145/188).
- 사건 제목 상자는 상태 배지처럼 양끝이 둥근 알약 모양이다. 반지름은 한 줄 상자 높이의 절반이고, 테두리는 배율과 관계없이 화면 기준 0.667px이다.
- 확대·축소 버튼과 전체 그래프 맞춤 버튼 사이에 지금 지도 배율을 퍼센트로 보인다. 값은 실제 배율(지도 좌표 1이 화면 1px일 때 100%)이고, 모바일에서는 숨긴다.

GraphCanvas가 기존 회원·모드별 필터 상태를 소유하고 MapPage 상단 슬롯에 GraphLegend를 portal로 표시한다. 상태를 복제하지 않는다. 기존 경로 강조의 필터 예외·호버·선택·카메라 저장 규칙을 유지한다. 왼쪽 제목·범례 창은 사용자 요청대로 제거한다. 지도 제목은 캔버스의 접근성 이름에 남긴다.

상단 메뉴와 필터는 좁은 화면에서 가로 스크롤하며 버튼을 축소하지 않는다. 캔버스의 고정 최소 높이를 해제해 낮은 창에서도 하단 확대 도구가 잘리지 않게 한다.

## 일반 서비스에 적용한 화면 표현

MapPage가 기본적으로 개선 appearance를 제공한다. 비교 도구의 명시적인 context가 있을 때만 기본 스타일로 되돌릴 수 있다. 개발 진입점이나 합성 인증 상태 없이 일반 서비스 경로에서도 같은 표현을 사용한다.

- 페이지·지도·상세 카드의 밝기와 간격을 구분한다. 선택된 모드·필터와 주요 행동은 채움색으로 표시한다.
- 일반 선 1.5px, 호버·선택 선 2.5px. 방향·화살표·연결 의미는 바꾸지 않는다.
- 기업·사건 이름은 15% 확대하고 글자 영역을 포함해 충돌을 재계산한다. 노드 지름과 활동량 기준은 유지하지만 일부 배치와 전체 맞춤 배율은 달라질 수 있다.
- 상단 도구 12px, 상세 본문 13px/20px, 섹션 제목 14px, 패널 제목 18px를 지도 범위의 공유 graphTypography로 적용한다. 기존 panelStyles를 계속 사용하며 다른 서비스 페이지의 기준을 바꾸지 않는다.
- 라이트·다크 스타일은 기존 서비스 테마를 따른다. 모바일 MapDetailSheet의 portal 경계에도 같은 토큰·타이포그래피를 전달한다.

## 노드 선택과 해제 시 지도 위치

- 2026-11-04 결정: 기본 지도의 노드는 처음 그린 자리에 고정한다. 기업을 골라 접힌 사건이 펼쳐지거나 상세창 때문에 지도 너비가 바뀌어도 다른 노드는 움직이지 않는다. 겹침 회피는 접힌 사건까지 넣고 처음 지도 크기로 한 번만 계산한다(`MAP_LAYOUT_REVISION` 11). 노드를 옮기는 것은 기업 중심 그래프(포커스)와 흐름 순 정렬뿐이다.
- 지도에서 노드를 클릭하거나 키보드로 선택하면 카메라를 옮기지 않는다. 상세창이 열린 뒤 그 노드가 가려질 때만 남은 지도 영역 중앙으로 옮긴다. 보유·관심 사이드바와 패널 행에서 고른 노드는 늘 중앙으로 옮긴다. 확대 배율은 유지하고, 모바일에서는 상세 시트에 가리지 않는 영역을 기준으로 한다. 라벨·후광을 제외한 원·마름모의 중심을 사용한다.
- 빈 곳 클릭·Esc·상세 닫기로 선택을 해제하면 기존 노드 좌표와 화면 위치를 유지한다. 상세창이 사라져 지도 너비가 늘어도 오른쪽으로 밀리지 않는다.
- 직접 드래그하거나 확대·축소하면 선택 노드 자동 중앙 유지를 멈춘다. 전체 그래프 맞춤을 누르면 현재 화면 크기에 맞게 카메라 위치·배율만 갱신한다.
- 회귀 검사에서 상세창 리사이즈 후 중앙 이동 순서, 전체 노드 좌표·카메라 보존, 재선택, 모바일 시트 영역, 명시적 전체 맞춤을 검증한다. 브라우저에서는 합성 데이터로 삼성전자·SK하이닉스 클릭과 빈 곳 클릭·Esc 해제를 확인했다.
