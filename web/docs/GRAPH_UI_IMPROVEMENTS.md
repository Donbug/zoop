# 지도 필터·표현·기업 로고 개선

D-GRP-01·01b·02·03·04·05 / M-GRP-01. 2026-10-21 사용자 확정 화면과 추가 요청을 기준으로 한다. main `1e5fa90`과 대조했다.

## 바뀐 동작

상단의 단순 개수 표기와 왼쪽 표시 필터를 하나의 상단 필터로 통합한다. 기업·사건·직접 관련·구조적 관련·후속 사건·사건 공유 버튼은 실제 노드·간선 visibility를 바꾸고, 개수는 전체 조회 스냅샷 기준으로 유지한다. 꺼짐 상태는 흐리게 표시하고 `aria-pressed`로 전달한다. 각 관계 설명은 기존 툴팁을 유지한다.

GraphCanvas가 기존 회원·모드별 필터 상태를 소유하고 MapPage 상단 슬롯에 GraphLegend를 portal로 표시한다. 상태를 복제하지 않는다. 기업·사건을 동시에 숨기지 않으며, 기존 경로 강조의 필터 예외·호버·선택·카메라 저장 규칙을 유지한다. 왼쪽 제목·범례 창은 사용자 요청대로 제거한다. 지도 제목은 캔버스의 접근성 이름에 남긴다.

상단 메뉴와 필터는 좁은 화면에서 가로 스크롤하며 버튼을 축소하지 않는다. 캔버스의 고정 최소 높이를 해제해 낮은 창에서도 하단 확대 도구가 잘리지 않게 한다.

## 일반 서비스에 적용한 화면 표현

MapPage가 기본적으로 개선 appearance를 제공한다. 비교 도구의 명시적인 context가 있을 때만 기본 스타일로 되돌릴 수 있다. 개발 진입점이나 합성 인증 상태 없이 일반 서비스 경로에서도 같은 표현을 사용한다.

- 페이지·지도·상세 카드의 밝기와 간격을 구분한다. 선택된 모드·필터와 주요 행동은 채움색으로 표시한다.
- 일반 선 1.5px, 사건 공유 점선 1.2px, 호버·선택 선 2.5px. 방향·화살표·연결 의미는 바꾸지 않는다.
- 기업·사건 이름은 15% 확대하고 글자 영역을 포함해 충돌을 재계산한다. 노드 지름과 활동량 기준은 유지하지만 일부 배치와 전체 맞춤 배율은 달라질 수 있다.
- 상단 도구 12px, 상세 본문 13px/20px, 섹션 제목 14px, 패널 제목 18px를 지도 범위의 공유 graphTypography로 적용한다. 기존 panelStyles를 계속 사용하며 다른 서비스 페이지의 기준을 바꾸지 않는다.
- 라이트·다크 스타일은 기존 서비스 테마를 따른다. 모바일 MapDetailSheet의 portal 경계에도 같은 토큰·타이포그래피를 전달한다.

## 기업 로고

- 네이버·Alphabet은 사용자가 제공한 SVG로 교체했다.
- KT·카카오는 제공 PNG를 SVG path로 윤곽 변환했다. KT는 16색 팔레트, 카카오는 배경·글자 윤곽을 사용한다. `tools/vectorize-brand-logos.py`는 Pillow·numpy를 쓰는 선택적 자산 변환 도구이며 서비스 실행·빌드에 새 의존성을 추가하지 않는다. 비트맵 원본 특성상 미세한 윤곽·색 단계 차이는 있을 수 있다.
- KT(`KRX:030200`) 매핑을 추가하고 삼성SDI(`KRX:006400`)는 삼성전자와 같은 로고를 사용한다. 이 교체 대상들은 이전 snapshot logoUrl보다 우선한다.
- 배경과 안전 여백이 확인된 로고는 원을 채운다. 나머지 심벌은 지름의 68% 영역에 가운데 배치하여 원형 경계에 잘리지 않게 한다. 공통 CompanyLogo도 같은 분류를 사용한다.
- 마이크론은 자산에서 확인한 검정(`#000000`), 아마존은 SVG 배경(`#232f3e`)으로 원의 흰 여백을 채운다. 개선 appearance도 이 배경을 보존한다. 로고 색은 다크 테마에서도 반전하지 않는다.
