## 1. 다크 목록 카드 대비

`relationship-map.css`의 기존 ID 선택자가 관련 기업 행과 버튼에 흰 배경을 강제하고,
지도 테마는 글자를 밝게 바꾸면서 대비가 사라졌음. `map-appearance-styles.ts`에서
같은 ID 범위를 가진 Tailwind 선택자로 목록 배경을 현재 `--map-surface`에 맞춤.
동일 원인의 사건 목록도 함께 적용하되 근거 보기 액션의 투명 배경은 유지.
hover/선택 상태는 기존 `--map-selected`를 사용하며 전역 토큰 값은 변경하지 않음.

실제 브라우저의 관련 기업 버튼 계산 스타일:

| 상태         | 배경    | 기업명  | 보조 문구 | 기업명 대비 | 보조 대비 |
| ------------ | ------- | ------- | --------- | ----------- | --------- |
| 수정 전 다크 | #ffffff | #fafafa | #d4d4d4   | 1.04:1      | 1.48:1    |
| 수정 후 다크 | #262626 | #fafafa | #d4d4d4   | 14.50:1     | 10.21:1   |

키보드 Enter로 관련 기업을 선택하면 aria-pressed=true와 배경 rgb(54,54,56)을 확인.

## 2. 모바일 전체 맞춤

통합한 #570에는 초기 렌더에서 전체 맞춤을 실행하는 수정이 이미 있음.
최종 PR 전 이미지 검토에서 새로 고침 후 빈 캔버스를 발견했고 실제 브라우저에서 재현함.
추가로 저장 카메라 복원과 두 맞춤 경계 문제를 수정함.

- G6 `getPosition()`은 지도 좌표, `translateBy()`는 화면 픽셀이다. 저장 위치 복원 시 차이에 저장 배율을 곱해 같은 화면 위치로 되돌린다. 20%에서 500 지도 단위는 100px이며, 이전에는 500px 이동해 노드가 화면 밖으로 밀렸다. 저장 데이터 형식은 바꾸지 않음. 이미 잘못 이동한 위치가 저장된 세션은 [전체 그래프 맞춤] 1회로 복구할 수 있다.
- 전체 보기에서는 LOD가 사건 제목을 숨기는데, 맞춤은 긴 전체 제목의 줄바꿈 높이까지 예약했음. `overviewFootprint`로 전체 맞춤에서 사건 제목 여백만 제외. 회사 이름과 모든 원·좌표는 유지.
- 가장 넓은 라벨을 전체 그래프 양 끝에 일괄 예약하던 방식을 노드별 화면 경계 계산으로 교체. 화면 공간에 들어가는 최대 배율을 기존 min/max 범위 안에서 탐색. 확대된 라벨 여백도 반영하고 좌표/배치/저장값을 바꾸지 않음. 위아래로 마주 보는 라벨이 최소 배율에서는 겹쳐 맞지 않다가 배율을 키우면 들어가는 경우, 먼저 들어가는 배율을 찾은 뒤 그 상한을 탐색한다(회귀 테스트 1건 추가).
- 특정 고정 배율을 새 최소값으로 강제하지 않음. 전체 맞춤은 전체 노드를 보는 용도이며 모든 사건 제목을 동시에 읽을 수 있다는 뜻은 아님.
- 기존 수동 이동·선택 복귀·패널 크기 변경 보존 정책은 유지. 해당 GraphCanvas 회귀 검사도 실행.

## 3. 선택 기업 주변 사건 제목

2026-11-04 리뷰 규칙("선택·hover한 노드에 연결된 사건 제목은 숨기지 않는다", `keep`)은 그대로 둠.
겹침은 제목을 숨기는 대신 배치로 해결함(2026-11-05 사용자 결정).

- 연결 제목은 기존 네 방향(위·아래·왼쪽·오른쪽) 중 빈자리를 먼저 찾음.
- 네 방향이 모두 차 있으면 원에서 제목 높이만큼씩 최대 4단계 더 밀어 빈자리를 찾음.
  위 제목은 위로, 아래 제목은 아래로, 옆 제목은 위나 아래로 밀림.
- 밀어낸 거리는 지도 단위로 저장해 배율이 바뀌어도 원과 함께 움직이며, 다음 계산에서 다시 정함.
- 4단계 안에서도 자리가 없을 때만 기존처럼 첫 방향에 겹쳐 표시함(규칙 유지).
- 선택한 노드 자체의 제목은 최우선(priority 0)으로 둠. 원·연결선·데이터는 바꾸지 않음.

전체 맞춤만 원과 제목을 함께 가운데에 둠. 선택·이웃 맞춤은 예전처럼 원들의 중심을
가운데에 두고, 제목이 들어갈 여백을 중심 기준 양쪽에 같게 잡음(`fitZoom` `centerOn: 'circles'`).
목록 행 hover 강조는 `@media (hover: hover)`에서만 적용해 휴대폰에서 누른 행이 강조된 채 남지 않음.

## 검증과 증거

- 변경 전 회귀 검사: 카드 테마 2건, 숨겨진 사건 제목 맞춤 1건, 선택 이웃 제목 충돌 1건 실패 확인. 추가한 노드별 라벨 경계 검사도 변경 전 실패 확인.
- 관련 테스트: `graph-geometry`, `graph-readability`, `graph-appearance`, `GraphCanvas.selection` 4파일 151건 PASS.
- 타입·린트·포맷·최종 빌드 PASS. 카메라 복원 추가 수정 전 전체140파일·1611건 PASS. 추가 수정 후 전체 140파일·1613건 중 1612건 PASS. 실패 1건(MainGraphCompletion, 5초 시간 초과)은 단독 재실행 49건 PASS.
- 실제 MapPage를 .env 없이 실행하고 기존 개발용 합성 그래프·기업 응답·비회원 세션으로 검증. 운영 데이터·회원 정보가 아님.
- 수정 전 서버는 통합 기준 커밋의 네 소스 파일을 읽고, 나머지 소스와 합성 입력은 수정 후와 동일하게 사용.
- 390px 새 진입·새로 고침·전체 맞춤, 1440px↔390px·844×390 전환, 라이트·다크, 기업/사건/관련 기업 키보드 선택 확인. 모바일 문서 scrollWidth=innerWidth=390.
- reduced-motion은 기존 카메라 테스트로 검증하며 OS 설정을 직접 바꿔 확인하지는 않음.
- 전후 이미지는 저장소에 넣지 않음(#570과 같은 기준).
