# PR #160 · 이메일 회원가입 및 인증 통합

## 반영한 결정

2026-10-14 `github-drafts/auth-pr159-160-review.md` 기준. #159의 쿠키 전용 `call`·`ApiError`·시작/소셜/비회원 UI를 통합하고 #160의 회원가입·동의·응답 유실 복구·세션 세대·FS006 분기를 유지했다. 같은 역할의 HTTP 함수·오류 클래스·세션 로더는 각각 하나다. Bearer/localStorage 토큰·refresh·storage 이벤트 인증은 제거했다.

쿠키 쓰기에는 회원/비회원 모두 세션 CSRF를 전송한다. 보호 라우트와 개인화 지도는 확인된 회원 세션만 인정한다. 서버 로그아웃 POST 후 화면 상태를 초기화한다(서버 오류는 성공으로 숨기지 않는다).

세션 조회·가입/로그인·401·로그아웃은 요청 시작 세대를 검사한다. 이전 요청은 새 회원 상태를 덮어쓰지 못한다. 회원 변경, 비회원 전환, 로그아웃, 현재 세션의 401에서 온보딩·AI·그래프 UI·지도 필터를 같은 경계에서 초기화한다.

## 이동 및 미확정 정책

로그인/가입 응답 뒤 GET session으로 재확인한다. 미완료 회원은 초기 설정, 완료 회원은 설정/보유 조회 후 전체 또는 개인화 지도. 둘 다 0개면 전체 지도. 기존 회원 자동 진입에도 같은 분기를 적용한다. 안전한 앱 내부 복귀 경로는 완료된 회원에게 유지한다.

**사용자 결정: 조회 실패 또는 partial이면 재시도만 제공.** 성공한 로그인/가입 POST를 반복하지 않고 세션·종목만 다시 확인한다. 종목 수를 모르는 상태를 0개로 추정하거나 임의 지도에 보내지 않는다.

비밀번호 상세 규칙과 표시 이름 길이는 미확정이다. 와이어프레임의 8자/20자 제한을 승인된 정책으로 제시하지 않는다. 비밀번호 공백은 그대로 전송한다. 커밋은 전역 AGENTS의 English Conventional Commits 규칙을 따른다.
