# 실제 지도에서 진행하는 튜토리얼

FS015 · 요구 15·16 · D-GRP-T/T2/T3/T4/T5 · M-GRP-01.

튜토리얼은 별도 예시 그래프 없이 기존 MapPage와 GraphCanvas 위에서 진행한다.
초기 설정을 완료하면 `/?mode=all&tour=1`로 진입한다. 보유·관심 종목이나
기존 개인/기업/회차 URL과 관계없이 튜토리얼에서는 시장 전체를 조회한다.
표시된 응답의 삼성전자와 직접·구조적으로 연결된 실제 사건을 안내 대상으로
고르며, 근거가 있는 연결을 우선한다. 대상이 없거나 조회가 실패하면 이를
표시하고 재시도·건너뛰기를 제공한다. 가상 노드를 주입하지 않는다.

## 단계와 입력

1. 지도 중앙에서 5시 방향, 짧은 변의 25% 거리에 있는 원형 영역을 끌어
   카메라를 이동한다. 이후 휠 또는 왼쪽 아래 확대·축소 버튼을 조작한다.
2. 삼성전자를 선택한다. 이동·휠·확대·축소·전체 맞춤을 계속 사용할 수 있고,
   단계 전환 때문에 카메라가 삼성전자로 자동 복귀하지 않는다.
3. 강조된 사건 또는 기업 상세의 같은 사건을 선택한다. 선택한 삼성전자의
   연결 이웃은 기존 밝기를 유지하지만 다른 노드 선택은 차단한다.
   사건 선택 영역의 지름은 기존 강조 원보다 15% 크다.
4. 영향 경로의 근거 버튼을 누른 뒤 문서가 성공적으로 로드되어야 진행한다.
   오류·빈 응답은 완료로 취급하지 않는다. 근거 창에서도 건너뛸 수 있다.
5. AI 버튼과 안내를 선명하게, 나머지는 반투명하게 표시한다. AI 버튼을 누르면
   질문 창이나 요청을 만들지 않고 기존 완료 저장 API로 튜토리얼을 마친다.
   마치기 버튼도 제공하며 건너뛰기는 표시하지 않는다.

1~4단계는 해당 동작·건너뛰기·실패 재시도만 허용한다. 메뉴, 필터, 잘못된
노드, 상세 닫기와 Escape로 진행 상태가 바뀌지 않도록 막는다. 모바일에서는
활성 상세 시트 안에 안내를 배치한다. 완료 저장 실패 시 안내와 재시도를
유지한다. 튜토리얼을 닫으면 기존 입력 상태와 일반 AI 동작을 복원한다.

## API 및 검증 경계

실제 API 튜토리얼의 영향 경로는 지도에 표시된 관계 상세를 조회한다.
승인된 INVOLVES/STRUCTURALLY_RELATED_TO 및 일치하는 기업·사건 끝점만 사용하며,
파생·미승인·부분 응답은 거부한다. 관계가 가진 근거 ID를 그대로 전달한다.
일반 영향 경로 조회와 근거 문서 API 계약은 변경하지 않는다.

회귀 테스트는 전체 조회 고정, 단계 우회 차단, 카메라 조작 유지, 선택 이웃
표시, 실패·재시도, 늦은 응답, 근거 성공 후 전환, AI 창 없는 완료 저장을
검증한다. 개발용 그래프·근거를 이용한 브라우저 확인은 실제 원문 조회 성공과
구분해야 한다. 로컬 임시 DB의 인증·초기 설정·완료 저장은 확인했지만 해당
DB에는 원문 자료가 없어 실제 근거 조회의 종단 검증은 별도로 필요하다.
