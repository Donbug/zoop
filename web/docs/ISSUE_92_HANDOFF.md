## 기능

뉴스/공시/전체 및 기업/사건별 범위, 고유 문서 수와 인용 수 구분, 문서 제목·출처·발행 시각·관련 설명·원문 링크 또는 원문 미제공 안내. 문서→인용→근거 상세, URL 상태와 지도 왕복 복원. 기업 전환 시 이전 문서·근거·범위를 해제한다.

직접 근거 URL도 현재 공개 문서 목록과 그 문서의 인용 ID에 속해야 한다. 다른 기업·사건·미래 발행 근거를 표시하지 않고 늦은 응답은 폐기한다. 재검토에서 문서 목록과 근거의 공개 버전·기준 시점 일치 검증을 추가했다(동일 시점의 다른 오프셋은 허용).

HTTP401/403은 새로운 오류 코드도 권한 오류로 구분한다. partial/failures는 뒤쪽 커서 페이지에서도 보존하고 고정 버전·시점으로 재시도한다. 제공된 분석만 표시하며 다른 기업 판정이나 문서/결과 버전이 다른 요약은 표시하지 않는다. 합성 분석은 따로 표시한다.

Tailwind 기존 Vite 설정, PR169 공통 셸·토큰을 사용한다. 추가 CSS 파일·CSS import·인라인 style·패키지 변경 없음. main의 강화된 공개 버전 검증도 유지한다.
