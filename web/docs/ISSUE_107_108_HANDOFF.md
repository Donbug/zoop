# #107·#108 출퇴근 브리핑 PR 인계

2026-10-16. 기준 main `71ff602`. D-BRF-01·02 / WBS 6.8.11·6.8.12 / FS028·029·030·031·033·035.

## 구현 범위

`GET /api/v1/briefings?date=&edition=morning|evening`의 발행본을 조회한다. 날짜 생략은 선택한 구분의 최신 회차 요청이다. 날짜·회차는 URL에 남아 뒤로가기로 복원된다. 예정·생성·발행·데이터 기준 시각과 지표의 관측·비교 시각을 구분한다. 시장 요약·KOSPI/KOSDAQ/원달러·서버 선정 최대 3개 이슈·선정 이유·관련 기업·근거 수를 표시하고 과거 회차를 실시간 값으로 재계산하지 않는다.

퇴근에는 서버의 `sinceMorning`을 사용해 신규·이어짐·빠짐과 근거 수 변화를 표시한다. 보도 시각의 정밀도와 null 근거 수를 보존한다. 같은 제목은 관련 기업으로 구분한다. 비교 정보가 없으면 이유를 표시한다.

로딩·발행 전·생성 중·실패·중단·권한·미발행·부분 실패·빈 상태·재시도를 구분한다. 날짜·회차 전환 뒤 늦은 응답은 폐기하며 응답의 날짜·구분이 요청과 다르면 거절한다. 정정 이력은 원문과 나란히 표시한다.

## 최종 검토 보완

- 부분 실패 회차를 다시 조회하는 동안 이전 발행 내용을 현재 응답으로 남기지 않는다. 재조회 실패도 이전 성공 내용을 지운다.
- 중단 상태는 retryable section failure가 있어도 재시도 버튼을 제공하지 않는다.
- 두 경우를 회귀 테스트에 추가했다.
- UI는 기존 zoop 토큰과 Tailwind만 사용한다. 사용하지 않는 `.briefing-*` CSS 199줄을 제거했으며 새 CSS·인라인 스타일·의존성은 없다.

## 분리와 한계

#109 회차 목록·회차 기준 지도, #110 개인화·평가를 포함하지 않는다. `prototype/` 코드를 가져오지 않는다. API 계약 변경·예약 생성·관리자 재처리·외부 시장 데이터·유료 AI 실행은 이 FE 변경의 범위가 아니다. 실제 발행 생산자와의 E2E는 미검증이다. 이 PR은 정본의 공개 조회 API consumer이며 조회 실패를 개발용 mock으로 바꾸지 않는다.
