## 동작과 검토 보완

- 공개 회차 이력의 날짜·출근/퇴근·중단 상태와 불투명 커서를 사용한다. 추가 페이지의 중복 회차·반복 커서·중복 클릭을 방어하며 실패 시 기존 이력을 유지한다. 최초 조회 실패는 날짜 직접 선택과 재조회로 복구한다.
- 발행본에서 `round`가 고정된 지도에 진입하고, 발행 당시 시각·정정 수와 브리핑 복귀를 제공한다. 현재 지도로 나갈 때 회차·시점·버전·선택을 함께 해제한다.
- 회차 기준 API가 available인지 확인한 뒤 해당 버전·시점으로 그래프를 요청한다. 미발행·중단·버전 부재·다른 회차/버전/시점은 현재 지도나 빈 성공으로 바꾸지 않는다. 같은 회차 재조회 실패도 이전 그래프를 지운다.
- 회차의 사건·기업·간선·영향 경로·근거는 고정 context를 전달하고 응답 ID·버전·시점을 검증한다. 개발용 mock으로 대체하지 않는다. 공통 지도 동작은 보존한다.
- 회차 지도에 한해 Tailwind로 모바일 최소 너비와 헤더·도구 모음 넘침을 보완했다. 새 CSS·의존성은 없다. 시세·재무·모의 보유는 기존 별도 조회 영역이며 회차의 관계·근거로 사용하지 않는다.

## 검증

전체 Vitest 33개 파일·307개 테스트 통과. 이후 모바일·재조회 처리 보완 뒤 관련 회귀를 재실행했다. ESLint·테스트 TypeScript·서식·빌드·diff 검사를 확인했다. Chromium 1440px·390px에서 회차 지도 왕복·제공 중단·문서 가로 넘침 없음·런타임 오류 없음을 합성 API로 검증했다. API 소비 경계의 고정 기준/오류와 mock 우회는 roundSnapshots 테스트로 확인한다.

실제 발행·관계 producer와의 E2E는 미검증이다. 외부 자료·유료 AI·배포는 실행하지 않았다. 기존 지도 번들 경고는 유지한다. 병합은 팀장이 담당한다.
