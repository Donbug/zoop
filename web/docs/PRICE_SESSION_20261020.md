# D-COM-05 · FS040 1일 거래 세션 적용

기준: 백엔드 전달 문서 `fe-1d-trading-session.md` (2026-10-20).

- 가격 `period=1d` 요청은 `from`을 보내지 않는다. 거래소 일정, 휴장일과 서머타임 계산은 서버가 담당한다.
- `PriceSeries.range`가 있으면 모든 기간에서 x축에 그대로 사용한다. 장중 오른쪽 끝은 서버의 `range.to`이며 미래 장 마감 시각으로 확장하지 않는다.
- `range`가 없는 기존 API는 기존 축 계산을 유지한다. 1일은 최근 24시간으로만 호환 처리하며 거래소 세션으로 표시하지 않는다.
- ‘1일’ 버튼은 유지한다. 서버가 제공한 `sessionDate`를 거래소 현지 거래일로 표시하고 축 시각은 기존 KST임을 안내한다. 미국 거래일을 한국 날짜로 바꾸지 않는다.
- 1일 사건 조회도 응답의 세션 구간을 사용한다. 응답 전/구형 API는 기존 조회 범위로 동작한다. 세션 밖 표식은 기존 범위 필터로 제외하며 별도 ‘다른 날’ 섹션은 추가하지 않는다.
- PR은 최신 main에서 차트 세션 변경만 분리했다. 새 API 실서버 호출은 검증하지 않았으며 테스트 응답으로 계약을 확인한다.

검증: 회사 상세 통합 테스트 및 세션 차트 테스트, 프론트 lint/build.
